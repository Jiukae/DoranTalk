> Play Console → 도란톡 앱 → **성장 → 스토어 등록정보 → 기본 스토어 등록정보** 에 그대로 붙여 넣어요.
> 그림 파일은 이 폴더에 있어요. GitHub에서 파일을 누르고 **Download raw file**(⬇)로 받아요.

## 앱 이름 (30자까지)
```
도란톡 - 가족 소식방
```

## 간단한 설명 (80자까지)
```
우리 가족끼리만 보는 사진·소식·채팅. 광고 없이 무료, 큰 글씨로 부모님도 쉬워요.
```

## 자세한 설명 (4000자까지)
```
멀리 있어도 매일 도란도란, 우리 가족만의 소식방 도란톡이에요.

가족 단톡방에 올린 아이 사진이 금방 묻혀 다시 찾기 힘들었나요?
부모님이 글씨가 작아서 읽기 어렵다고 하셨나요?
도란톡은 초대받은 가족만 들어오는 작은 공간이에요.

■ 이런 걸 할 수 있어요
• 소식: 사진과 글을 올리고 하트와 댓글로 이야기 나눠요
• 채팅: 가족끼리 바로 대화하고, 아직 안 읽은 사람 수도 보여요
• 여러 그룹: 우리집 · 외가 · 친가를 따로 만들어 한 곳에서 봐요
• 알림: 새 소식과 채팅을 알림으로 알려 드려요
• 화면 색: 화이트 · 블랙 · 베이지 · 블루 중에 골라요

■ 우리 가족만 봐요
• 아이디로 초대하고, 초대를 수락한 사람만 그룹의 글 · 사진 · 채팅을 볼 수 있어요
• 다른 그룹 사람이나 낯선 사람은 볼 수 없어요
• 광고가 없고, 개인정보를 팔지 않아요 (서비스 운영에 꼭 필요한 곳에만 맡겨요 — 개인정보처리방침 참고)

■ 부모님도 쉽게
• 큰 글씨, 단순한 화면, 꼭 필요한 버튼만 있어요

■ 아이와 함께
• 만 14세 미만 어린이는 보호자 동의를 받아 가입해요
• 어린이는 보호자가 있는 그룹에만 들어갈 수 있고, 그룹을 만들 때도 보호자 승인을 받아요

■ 시작하는 방법
1. 회원가입 (이메일 · 아이디 · 닉네임)
2. 새 그룹 만들기
3. 가족에게 아이디를 물어보고 초대하기

도란톡은 무료예요.
문의: admin@dorantalk.com
웹에서도 쓸 수 있어요: https://dorantalk.com
```
