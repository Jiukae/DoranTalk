# 15단계 안내서 — 안드로이드 앱(APK) 직접 설치 · 알림 팝업

> 소요 시간: 5분 · 비용: 무료 · Play 스토어 필요 없음

## 왜 APK 인가요?
- 홈 화면에 추가한 도란톡(웹 앱 · PWA)의 알림은 안드로이드가 **"보통" 중요도**로 정해 둬서, 위쪽에 **아이콘만** 뜨고 팝업은 안 떠요.
  휴대폰 설정을 바꿔도 안 되는 휴대폰이 있어요.
- **도란톡 APK** 는 알림 종류를 처음부터 **"높음" 중요도**로 만들어서, 카카오톡처럼 **위에 팝업**(앱 이름 + 내용)으로 떠요.
- 화면은 웹과 똑같아요. 웹사이트를 고치면 **APK 앱에도 바로** 반영돼요. (APK 를 다시 설치할 일은 거의 없어요)
- 주소창 없이 앱처럼 열려요. (`www.dorantalk.com/.well-known/assetlinks.json` 에 이 앱의 서명 지문이 있어서)

## 어디서 받나요?
- 안드로이드로 도란톡에 로그인하면 홈 맨 위에서 **"도란톡 안드로이드 앱을 설치할까요?"** 라고 물어봐요 → **설치하기**
  - 누르면 바로 내려받고, 그 자리에 설치 방법이 나와요. ("나중에"를 누르면 2주 동안 안 물어봐요. 이미 설치한 휴대폰에는 안 물어봐요)
- **도란톡 → 사용 방법 → 앱 설치하기 → "안드로이드 앱 받기"** 버튼 (로그인 안 해도 돼요)
  - 바로 받는 주소: `https://www.dorantalk.com/download/dorantalk.apk`
- 안드로이드에는 이제 **"홈 화면에 추가"를 안내하지 않아요.** (그렇게 만든 도란톡은 알림이 아이콘으로만 와서요)
  아이폰은 홈 화면에 추가해야 알림을 받을 수 있어서 그대로 안내해요.
- 파일: `download/dorantalk.apk` (업로드 키로 서명됨, 안드로이드 7.0 이상, 약 0.9MB)

> 업로드 키(`dorantalk-upload-key.jks`)와 비밀번호는 14단계 때 받은 그대로예요. 다음에 앱을 고칠 때 필요하니 잘 보관해 주세요.

## 설치하기 (갤럭시 기준)
1. 크롬으로 도란톡 → **사용 방법** → **안드로이드 앱 받기** (크롬이 "위험할 수 있는 파일"이라고 물으면 **다운로드**)
2. 예전에 홈 화면에 추가한 도란톡이 있으면 **먼저 지워요.** (아이콘 길게 누르기 → 삭제, 또는 설정 → 애플리케이션 → 도란톡 → 삭제)
   - 이름 · 아이콘이 같아서 헷갈리고, 남아 있으면 알림이 예전 앱으로 갈 수 있어요.
   - 로그인 정보는 크롬에 남아 있어서, 보통 새 앱에서도 로그인된 채로 열려요. (안 되면 다시 로그인)
3. 받은 파일을 열어요: 알림창의 **다운로드 완료**, 또는 **내 파일 → 다운로드 → dorantalk.apk**
4. **"출처를 알 수 없는 앱"** 안내가 나오면 **설정** → **이 출처 허용** 켜기 → 뒤로
5. **설치** → Play 프로텍트가 "알 수 없는 앱"이라고 하면 **세부정보 더보기 → 무시하고 설치**
6. **열기** → 도란톡이 주소창 없이 열려요

## 알림 켜기 · 팝업 확인
1. 도란톡 → 오른쪽 위 **내 정보** → **알림**
2. **알림 켜기**가 보이면 누르고 → 휴대폰이 "도란톡에서 알림을 보내도록 허용할까요?" → **허용**
   (이미 "알림을 받고 있어요"라고 나오면 그대로 두면 돼요)
3. **시험 알림 보내기** → 몇 초 안에 화면 위에 **도란톡 팝업**이 내려오면 성공 🎉
4. 팝업이 안 뜨면: 설정 → 알림 → 앱 알림 → 도란톡 → **알림 팝업** 체크 확인

## 가족에게 나눠 주기
- 안드로이드 가족에게는 "도란톡 → **사용 방법** → **안드로이드 앱 받기**"라고 알려 주면 돼요.
- 아이폰은 APK 를 못 써요. 지금처럼 **사파리 → 홈 화면에 추가**한 도란톡을 쓰면 돼요. (아이폰은 원래 위에 배너로 떠요)

## 다음에 앱을 고칠 때
- 화면 · 기능은 **웹만 고치면** 앱에 바로 반영돼요.
- 앱 아이콘 · 이름 · 알림 방식 같은 안드로이드 부분을 바꿀 때만 `android/app/build.gradle` 의 **versionCode 를 1 올리고** 새 APK 를 만들어 **같은 업로드 키로** 서명해요. Claude 에게 부탁하면 돼요.
  (다른 키로 서명하면 덮어 설치가 안 되고, 주소창도 다시 생겨요)
- 새 APK 는 `download/dorantalk.apk` 를 바꾸고, `js/install.js` 의 `ANDROID_APP` 버전 · 크기도 함께 바꿔요.

## 체크리스트
- [ ] 사용 방법 → 안드로이드 앱 받기 → 예전 도란톡(홈 화면 앱) 삭제 → 설치 → 주소창 없이 열리는지
- [ ] 내 정보 → 알림 → 시험 알림 → **위에 팝업**으로 뜨는지
- [ ] 안드로이드 가족에게 "사용 방법 → 안드로이드 앱 받기" 알려 주기
