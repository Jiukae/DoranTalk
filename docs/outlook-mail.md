# admin@dorantalk.com 문의 메일을 Outlook(윈도우 · 새 Outlook)에서 보기 · 답장하기

> 소요 시간: 약 10분 · 비용: 무료
>
> 화면 이름은 가끔 바뀌어요. 비슷한 메뉴를 찾거나, 막히면 화면을 캡처해 보여 주세요. (비밀번호 · 키가 보이는 부분은 가리고!)

## 어떻게 연결되나요?
admin@dorantalk.com 은 메일함이 따로 없는 **전달 주소**예요. (8단계 ImprovMX → gjiukae@gmail.com 으로 전달)
**새 Outlook**의 IMAP 화면에는 "IMAP 사용자 이름" 칸이 없어서, admin@ 주소로 지메일에 바로 붙일 수가 없어요. 그래서 이렇게 해요.

| 하는 일 | 방법 |
|---|---|
| **받기** | Outlook에 **지메일 계정(gjiukae@gmail.com)** 을 **구글 로그인**으로 추가 (앱 비밀번호 필요 없음) |
| **admin@ 으로 답장** | 지메일에 **"다른 주소에서 메일 보내기"** 로 admin@dorantalk.com 을 등록 (보내기는 Resend) → **답장은 지메일(웹 · 휴대폰 앱)에서** |

- ⚠️ Outlook에는 **gjiukae@gmail.com 으로 오는 메일이 모두** 보여요. (admin@ 문의 메일도 여기로 전달되니까요)

| 순서 | 할 일 | 걸리는 시간 |
|---|---|---|
| A | Outlook에 지메일 계정 추가 (받기) | 3분 |
| B | 지메일에 admin@ 보내기 주소 등록 | 5분 |
| C | Outlook에서 admin@ 으로 답장 · 시험 | 2분 |

---

## A. Outlook에 지메일 계정 추가 (받기)
1. **Outlook (new)** → 오른쪽 위 **⚙️ (설정)** → **계정** → **전자 메일 계정** → **+ 계정 추가**
2. `gjiukae@gmail.com` 입력 → **계속**
   - 공급자를 고르라고 나오면 **Google**
   - "Microsoft 클라우드와 동기화" 안내가 나오면 **계속**
3. 구글 로그인 창 → **gjiukae@gmail.com** 로그인 → "Microsoft 앱이 … 액세스하려고 합니다" → **허용**
4. 왼쪽 목록에 **gjiukae@gmail.com** 이 생기면 받기 끝 🎉
   - 다른 메일에서 `admin@dorantalk.com` 으로 "시험" 메일을 보내 보세요. 1~2분 뒤 Outlook에 오면 성공.

> 앞에서 **앱 비밀번호(Outlook)** 를 만들었다면 이제 필요 없어요.
> https://myaccount.google.com/apppasswords → `Outlook` 옆 **🗑 삭제** (안 쓰는 비밀번호는 지워 두는 게 안전해요)

## B. 지메일에 admin@ 보내기 주소 등록
이미 8단계 **B-5** 를 했다면 건너뛰어요. (지메일 설정의 "다른 주소에서 메일 보내기"에 admin@dorantalk.com 이 있으면 한 거예요)

1. 컴퓨터 크롬에서 **gjiukae@gmail.com** 지메일 → 오른쪽 위 **⚙️** → **모든 설정 보기** → **계정 및 가져오기**
2. **다른 주소에서 메일 보내기** → **다른 이메일 주소 추가**
3. 이름 `도란톡` · 이메일 주소 `admin@dorantalk.com` · **별칭으로 처리** 체크 그대로 → **다음 단계**
   - ⚠️ 이름 칸에는 구글 계정 이름(예: 지우개)이 **미리 채워져 있어요.** 꼭 지우고 `도란톡` 으로!
   - 이미 등록했는데 이름이 다르면: 목록의 admin@dorantalk.com 옆 **정보 수정** → 이름 `도란톡` → 저장
4. 이렇게 입력 → **계정 추가**
   | 칸 | 넣을 값 |
   |---|---|
   | SMTP 서버 | `smtp.resend.com` |
   | 포트 | `587` |
   | 사용자 이름 | `resend` |
   | 비밀번호 | Resend **API 키** (`re_` 로 시작 · Sending access · dorantalk.com) |
   | 보안 | **TLS를 사용한 보안 연결** |
   - 키가 없으면: **resend.com → API Keys → Create API Key** (Name `gmail`, **Sending access**, Domain `dorantalk.com`) → 복사
   - ⛔ 키는 이 지메일 칸에만 넣어요. 대화창 · GitHub · 카톡에는 붙여넣지 마세요.
5. 지메일이 admin@dorantalk.com 으로 **확인 메일**을 보내요 → ImprovMX가 다시 지메일로 넘겨 줘요
   → 받은 메일의 **확인 링크**를 누르거나 **확인 코드**를 입력 → 완료
6. (확인) 같은 화면 **"메일에 답장할 때:"** 가 **"메일을 받은 주소에서 답장하기"** 로 되어 있으면 좋아요.

## C. Outlook에서 admin@ 으로 답장 · 시험 (선택 — 추천은 지메일에서 답장)
> 새 Outlook에서 보낸 사람을 admin@ 으로 바꿔 보내면, 받는 쪽에 **"gmail.com 경유(via gmail.com)"** 표시나 구글 계정 이름이 붙을 수 있어요.
> 깔끔하게 **도란톡 &lt;admin@dorantalk.com&gt;** 으로 보내려면 **읽기는 Outlook, 답장은 지메일**에서 하세요. (B-6 덕분에 admin@ 으로 온 메일에 답장하면 자동으로 admin@ 으로 나가요)

1. Outlook에서 A-4의 시험 메일을 열고 **회신**
2. 위쪽에 **보낸 사람** 칸이 보이면 → 눌러서 **admin@dorantalk.com** 선택 (목록에 없으면 **다른 전자 메일 주소** → `admin@dorantalk.com` 입력)
   - **보낸 사람** 칸이 안 보이면: 메일 쓰는 화면 위쪽 **옵션** → **보낸 사람 표시**
3. **보내기** → 다른 메일함에 **도란톡 &lt;admin@dorantalk.com&gt;** 으로 도착하면 성공 🎉
   - 처음 몇 번은 스팸함으로 갈 수 있어요. ("스팸 아님"으로 표시)
   - **gjiukae@gmail.com 으로 도착했다면**: Outlook이 이 계정에서 보낸 사람 바꾸기를 못 하는 경우예요.
     이때는 **답장만 지메일(웹 · 휴대폰 지메일 앱)에서** 해 주세요. B-6 설정 덕분에 admin@ 으로 온 메일에 답장하면 **자동으로 admin@ 으로** 나가요.
   - **주소는 admin@ 인데 이름이 구글 계정 이름(예: 지우개)으로 보이면**: 새 Outlook은 보낸 사람 이름을 **구글 계정 이름**에서 가져와요.
     답장만 지메일에서 하거나, 구글 계정 이름을 `도란톡` 으로 바꿔요(myaccount.google.com → 개인 정보 → 이름 — 이 계정의 **모든** 메일 · 유튜브 이름이 바뀌니 도란톡 전용 계정일 때만).

## 알아 두기
- **보내기 한도**: Resend 무료는 **하루 100통 · 한 달 3,000통**이고, 가입 인증 · 비밀번호 찾기 메일과 **합쳐서** 세요. 문의 답장 정도는 충분해요.
- **보안**: 노트북을 잃어버리면 구글 계정 → **보안** → **내 기기**에서 그 기기 로그아웃, Resend **API Keys** 에서 지메일용 키 삭제 후 새로 만들기.
- 문의 메일은 법에서 "지체 없이" 처리하라고 해요. 보통 **10일 안에** 답하면 돼요. (8단계)

- [ ] (A) 앞에서 만든 앱 비밀번호(Outlook) 삭제
- [ ] B. 지메일 → 다른 주소에서 메일 보내기 → admin@dorantalk.com (smtp.resend.com · 587 · resend · re_ 키) → 확인
- [ ] C. 답장은 지메일에서 → 받는 쪽에 "도란톡 <admin@dorantalk.com>" 확인 (Outlook에서 보내기는 선택)
