# 3단계 안내서 — 가족 그룹 · 닉네임 초대 · 수락/거절

> 소요 시간: 약 10분 · 준비물: 컴퓨터(SQL 실행), 휴대폰 + 두 번째 계정

3단계에서 만든 것

- **홈 화면**: 받은 초대(수락/거절) + 내 가족 그룹 목록
- **가족 그룹 만들기**: 만든 사람이 방장이 돼요
- **닉네임으로 초대**: 그룹 화면 아래 **가족** 탭에서
- **초대 취소**, **그룹 이름 바꾸기(방장만)**, **그룹 나가기**
- 그룹 화면 아래쪽 탭: **소식 · 채팅 · 가족** (소식은 4단계, 채팅은 5단계에서 채워져요)
- 그룹이 하나뿐이면, 앱을 열자마자 그 그룹으로 바로 들어가요 (부모님이 헤매지 않게)

## A. 데이터베이스 업데이트 (꼭 해 주세요!)

3단계에서 "초대 취소" 기능과 "초대 대기 중인 사람 닉네임 보기"를 위해 `schema.sql` 을 조금 고쳤어요.
1단계 때처럼 **다시 한 번 실행**해 주세요. 이미 있는 데이터(가입한 계정 등)는 그대로 남아요.

1. GitHub에서 **Jiukae/TalkFeed** → 브랜치 **claude/talkfeed-family-app-qyi292** →
   **supabase** 폴더 → **schema.sql** 을 엽니다.
2. 오른쪽 위 **복사 아이콘(Copy raw file)** 을 누릅니다.
3. Supabase → 왼쪽 메뉴 **SQL Editor** → **+ (New query)** 를 누릅니다.
   (1단계 때 쓴 탭이 남아 있다면, 그 안의 내용을 **Ctrl+A** 로 전부 선택하고 지운 뒤 붙여넣어도 돼요)
4. **Ctrl + V** (맥은 **⌘ + V**)로 붙여넣고 **Run** 을 누릅니다.
5. 경고 창이 뜨면 **Run this query** 를 누릅니다.
6. **Success. No rows returned** 가 보이면 끝!
7. 휴대폰에서 **https://talkfeed.netlify.app/#/check** 를 열어 **"데이터베이스 최신 버전"** 이 초록색 ✓ 인지 확인하세요.

> - GitHub의 schema.sql 화면을 **새로고침(F5)** 한 다음 다시 복사해 주세요. (예전에 열어 둔 화면이면 옛날 내용이 복사돼요)
> - 붙여넣은 SQL 맨 위에 **`★ 버전 3`** 이라고 써 있는지 확인하세요.
> - SQL Editor에 예전 내용이 남아 있지 않게, **Ctrl+A로 전부 지운 뒤** 붙여넣고 Run 하세요.

## B. 휴대폰으로 확인하기 (두 사람 역할 해 보기)

초대를 시험하려면 **계정이 2개** 필요해요. 방법은 둘 중 편한 걸로 고르세요.

- **방법 1 (추천)**: 가족 한 명에게 부탁해서, 그분 휴대폰으로 https://talkfeed.netlify.app 에 들어가 가입하게 하기
- **방법 2 (혼자 할 때)**: 내 휴대폰은 지금 계정으로 두고, **컴퓨터의 크롬에서 시크릿 창**(Ctrl+Shift+N)을 열어
  두 번째 계정을 만들기. 이메일은 `test2@example.com` 처럼 아무거나 써도 돼요.
  (이메일 인증을 꺼 두었기 때문에 진짜 메일이 아니어도 가입돼요)

아래에서 **나** = 내 휴대폰, **상대** = 두 번째 계정이에요.

| # | 누가 | 해 볼 것 | 이렇게 되면 정상 |
|---|---|---|---|
| 1 | 나 | 홈에서 **+ 새 가족 그룹 만들기** → 이름 입력 → **그룹 만들기** | 그룹이 생기고 **가족** 탭이 열려요. 내 이름 옆에 **나**, **방장** 표시 |
| 2 | 나 | 초대 칸에 **없는 닉네임** 입력 → **초대 보내기** | "찾을 수 없어요" 빨간 안내 |
| 3 | 상대 | 가입하고 홈 화면 보기 | "아직 가족 그룹이 없어요" + 내 닉네임 크게 표시 |
| 4 | 나 | 상대의 닉네임으로 **초대 보내기** | "초대를 보냈어요" + **수락을 기다리는 초대 1개** 에 상대 이름 |
| 5 | 상대 | 홈 화면 (안 보이면 앱을 다시 열기) | **📩 받은 초대 1개** 카드에 그룹 이름 |
| 6 | 상대 | **수락하기** | 그룹 화면으로 들어가요. **가족** 탭에 2명 |
| 7 | 나 | **가족** 탭 다시 열기 | 상대가 멤버 목록에 보여요 |
| 8 | 상대 | **가족** 탭 맨 아래 **이 그룹에서 나가기** → 확인 | 홈으로 돌아가고 그룹이 사라져요 |
| 9 | 나 | 상대를 다시 초대 → 상대가 **거절** | 상대 홈에서 초대가 사라지고, 그룹 내용은 보이지 않아요 |
| 10 | 나 | 아무나 초대한 뒤, 대기 목록의 **취소** 누르기 | 대기 목록에서 사라져요 |
| 11 | 나 | 앱을 닫았다가 다시 열기 (그룹이 1개일 때) | 바로 그 그룹 화면이 열려요 |

**Supabase에서도 확인해 보기 (선택)**
- **Table Editor** → **family_groups**: 만든 그룹
- **group_members**: 멤버 목록 (owner = 방장)
- **group_invitations**: 초대 기록 (pending 대기 / accepted 수락 / declined 거절 / canceled 취소)

문제가 있으면 **몇 번에서 어떤 글자가 떴는지** 알려 주시거나 화면을 캡처해 주세요.
