# 17단계 안내서 — 광고 시작하기 (엄마랑 주말에 한 번)

> **내 카톡 · 네이버 · 인스타 계정은 없어도 돼요.** 광고 · 홍보는 원래 **어른 계정**으로 해야 해서, **엄마 계정**으로 해요.
> 평일에 내가 할 일은 **하루 1분, 도란톡 앱에서 숫자 보기**뿐이에요. 카톡 · 유튜브 · 쇼츠를 안 봐도 돼요.
>
> 비용: **35,000원** (네이버 검색 광고 7일). 미리 충전한 돈을 다 쓰면 광고가 **저절로 멈춰서** 돈이 더 나갈 일이 없어요.

## 한눈에

| 언제 | 누가 | 할 일 | 시간 |
|---|---|---|---|
| 주말 전 아무 때나 | **나** | 1. 준비 (데이터베이스 업데이트 · 가입 시험) | 20분 |
| 주말 한 번 | **엄마** (나는 옆에서 돕기) | 2. 카톡으로 소개 · 맘카페 글 · 네이버 광고 켜기 | 1시간 |
| 평일 매일 | **나** | 3. 도란톡 → 내 정보 → **광고 성과** 보고 적기 | 1분 |
| 다음 주말 | **엄마랑 나** | 4. 결과 보고 계속할지 정하기 | 15분 |

## 이번에 앱에 새로 들어간 것
1. **광고 성과 화면 (운영자만)**: 운영자 계정(admin@dorantalk.com)으로 로그인 → **내 정보 → 광고 성과 (운영자)**
   - **어디서 보고 가입했는지** (오늘 · 7일 · 전체) · **가족과 연결** · 날짜별 가입 · 주마다 활동한 가족 수
   - 숫자만 보여요. 이름 · 이메일 · 글 · 사진 · 채팅 내용은 보지 않아요. (데이터베이스 버전 12)
2. **카톡 · 네이버 앱 안에서 링크를 눌러도 가입 경로가 이어져요**
   - 엄마가 카톡으로 보낸 링크를 받은 사람이 "크롬/사파리로 열기"를 눌러 가입해도, 예전처럼 "직접 · 기타"로 사라지지 않고 **`family`** 로 잡혀요.

## 1. 내가 할 일: 준비 (컴퓨터, 20분)

### 1-1. 데이터베이스 업데이트
아직 안 한 것만 **순서대로** 해요. (GitHub → **supabase → updates** → 파일 열기 → 📋 전체 복사 → Supabase **SQL Editor** → **+ New query** → 붙여넣기 → **Run**)
1. `v9_to_v10.sql` → "업데이트 완료! 버전 10" (13단계 · 아직 안 했다면)
2. `v10_to_v11.sql` → "업데이트 완료! 버전 11" (16단계 · 프로필 사진)
3. `v11_to_v12.sql` → "업데이트 완료! 버전 12" (이번 · 광고 성과)
4. 운영자 계정으로 로그인 → **내 정보 → 연결 점검 (운영자)** → "최신 버전(12)" 초록색

> 몇 번째 파일부터 해야 할지 모르겠으면 **연결 점검**을 먼저 열어 보세요. 실행할 파일을 순서대로 알려 줘요.

### 1-2. 가입 인증 메일 켜기 (아직 안 했다면)
모르는 사람이 가짜 이메일로 마구 가입하는 걸 막아요. **10단계 B-2** 를 따라 **Confirm email** 을 켜요.

### 1-3. 가입 경로가 잘 잡히는지 시험
1. **시크릿 창**에서 `https://www.dorantalk.com/welcome?from=test` → **무료로 시작하기** → 평소 안 쓰는 이메일로 가입
2. 운영자 계정 → **내 정보 → 광고 성과** → **`test` 1명**이 보이면 성공
3. 시험한 계정은 **내 정보 → 회원 탈퇴** (탈퇴하면 숫자에서도 빠져요)

## 2. 엄마가 할 일 (주말, 약 1시간)
> 👩 **이 부분을 엄마에게 보여 주세요.** 아래 글은 그대로 복사해서 쓰시면 돼요.

### A. 카카오톡으로 소개하기 (10분) — 가장 효과가 커요
가족 앱은 아는 사람이 "이거 써 봐" 하고 보내 주는 게 제일 잘 통해요.
친한 가족 · 친구 **3~5명**(또는 가족 단톡방)에게 아래를 보내 주세요.

```
요즘 저희 가족은 '도란톡'이라는 가족 소식방을 써요.
사진이랑 소식을 가족끼리만 나눌 수 있고, 글씨가 커서 부모님도 쉽게 쓰세요.
광고 없고 무료예요. 저희 가족이 직접 만든 앱이라 써 보시고 의견 주시면 고칠게요 😊
👉 https://www.dorantalk.com/welcome?from=family
```

- 보내기 전에 엄마 카톡 **나와의 채팅**에 먼저 보내서 눌러 보면 좋아요. 그림과 "도란톡" 제목이 나오면 정상이에요.

### B. 맘카페 홍보 게시판에 글 쓰기 (15분)
자주 가시는 맘카페 · 지역 카페의 **홍보 게시판**(규칙 먼저 확인)에 올려 주세요.

**제목**
```
가족끼리만 쓰는 무료 소식방 앱을 저희 가족이 직접 만들었어요 (광고 없음)
```
**본문**
```
안녕하세요. 가족 단톡방에 아이 사진을 올리면 금방 묻혀서 다시 찾기 힘들고,
부모님은 글씨가 작다고 하셔서 우리 가족끼리만 쓰는 소식방을 직접 만들었어요. 이름은 도란톡이에요.

- 사진과 소식은 초대받아 수락한 가족만 볼 수 있어요
- 하트 · 댓글, 가족 채팅, 휴대폰 알림
- 글씨와 버튼이 커서 부모님도 쉽게 쓰세요
- 광고 없고 무료예요

저희 가족은 잘 쓰고 있어서, 필요하신 분들께 나누고 싶어 소개드려요.
써 보시고 불편한 점 알려 주시면 고쳐 볼게요 🙏
👉 https://www.dorantalk.com/welcome?from=cafe
```
- 사진을 같이 올리면 좋아요: GitHub `marketing/insta-1-intro-1080.png`, `marketing/insta-2-features-1080.png`

### C. 네이버 검색 광고 켜기 (30분)
누가 네이버에서 **"가족 앨범 앱"** 같은 걸 검색할 때 도란톡이 위에 보여요.
**광고를 눌렀을 때만** 돈이 나가고, 보이기만 하면 0원이에요.

**C-1. 광고 계정 만들기**
1. **https://searchad.naver.com** → **신규가입** → **개인 광고주** → 엄마 네이버 아이디로 가입
2. **광고시스템** 들어가기

**C-2. 광고 만들기**
1. **+ 새 캠페인** → **파워링크 유형** → 이름 `도란톡 첫 광고` · **하루 예산 5,000원**
2. **광고그룹 만들기** → 이름 `가족 앱 찾는 사람`
   - **URL**: `https://www.dorantalk.com` (사이트 등록이 처음이면 이 주소로 등록)
   - **기본 입찰가**: 처음엔 **낮게** (예: 200원). 3일 동안 노출이 거의 없으면 조금씩 올려요.
   - 매체: **모바일 · PC 모두**
3. **키워드** — 아래를 그대로 붙여넣기
   ```
   가족앱
   가족 앱
   가족 사진 공유
   가족 사진 공유 앱
   가족 앨범 앱
   가족앨범
   가족 채팅 앱
   가족 소통 앱
   가족 소식
   부모님 사진 공유
   육아 사진 공유
   가족 단톡방
   ```
   (다른 회사 앱 이름은 넣지 않아요)
4. **소재 (광고 문구)**
   - 제목: `우리 가족만의 소식방 도란톡` (글자 수가 넘치면 `우리 가족만의 소식방`)
   - 설명: `사진·소식·채팅을 가족끼리만. 큰 글씨와 쉬운 화면이라 부모님도 편해요.`
   - **연결 URL**: `https://www.dorantalk.com/welcome?from=naver_ad`
   - 표시 URL: `www.dorantalk.com`
5. **비즈머니 충전**: **35,000원만** 충전해요. 다 쓰면 광고가 저절로 멈춰요.
6. **검수**(검토)가 끝나면 시작돼요. 보통 1~2일 걸려요.
   - 거절되면 그 사유를 캡처해서 보여 주세요. 사이트에 필요한 걸 넣어 드릴게요.

> 도란톡에는 광고 추적 코드(네이버 · 구글 · 메타 픽셀 등)를 **넣지 않아요.** 아이들도 쓰는 앱이라서요.
> 그래서 효과는 도란톡의 **광고 성과 화면 숫자**(`naver_ad`)로 봐요.

## 4. 다음 주말: 엄마랑 같이 정하기 (15분)
1. 엄마: 네이버 광고 (searchad.naver.com 또는 **네이버 광고 앱**) → 캠페인 → **노출수 · 클릭수 · 총비용**
2. 나: 일주일 동안 적은 표 + 광고 성과 화면의 **7일** 숫자
3. 계산해 보기
   - 가입 1명당 비용 = 네이버 광고비 ÷ `naver_ad` 가입 수 (예: 35,000원 ÷ 7명 = 5,000원)
   - 가족 1명당 비용 = 광고비 ÷ 가족과 연결 수

| 이런 결과면 | 이런 뜻이에요 | 이렇게 해요 |
|---|---|---|
| **노출이 거의 없음** (하루 수십 번 아래) | 입찰가가 낮거나, 그 키워드를 찾는 사람이 적어요 | 입찰가를 조금 올리거나 키워드를 더 넣어요 |
| 노출은 많은데 **클릭이 거의 없음** | 광고 문구가 눈에 안 띄어요 | 문구 모음 7번의 다른 제목 · 설명으로 바꿔요 |
| 클릭 **30번 이상**인데 가입 **0~1명** | 소개 화면에서 마음이 바뀌어요 | 소개 화면을 캡처해 보여 주세요. 같이 고쳐요 |
| 가입은 되는데 **가족과 연결 0** | 가입 뒤 가족 초대가 어려워요 | 알려 주세요. 초대 과정을 더 쉽게 고쳐요 |
| 가입 1명당 **5,000원 이하** + 가족과 연결이 **절반 이상** | 잘 되고 있어요 🎉 | 한 주 더 하거나 하루 예산을 조금 늘려요 |
| `family` · `cafe` 가 `naver_ad` 보다 많음 | 돈 드는 광고보다 소개가 잘 통해요 | 광고비 대신 소개를 더 해요 (다른 카페 · 다른 친구) |

> **결과 화면(광고 성과 + 네이버 광고)을 캡처해서 보여 주세요.** 같이 보고 다음에 할 걸 정해요.
> 광고를 멈추고 싶으면: 네이버 광고 → 그 캠페인 → **OFF**. 남은 비즈머니는 다음에 다시 쓸 수 있어요.

## 5. 그다음 (잘 됐을 때)
- 광고 성과 화면에서 **가족과 연결**이 많이 나온 곳에 시간 · 돈을 더 써요.
- 4주가 지나면 **주마다 가족 활동** 숫자로 "가입한 가족이 계속 쓰는지"도 봐요. (10단계 D-2)
- 유튜브 광고(구글) · 인스타 광고는 계정이 생기고 여유가 있을 때 해요. (10단계 F-1 · F-3, 주소 끝 `google_ad` · `insta_ad`)

## 꼭 지킬 것
- **직접 만든 서비스라고 밝혀요.** ("저희 가족이 직접 만든 앱이에요") 이용자인 척 쓴 후기는 안 돼요.
- 카페는 **홍보 게시판**에만, 규칙을 먼저 확인해요.
- **어린이에게 광고하지 않아요.** 유튜브는 "아동용 아님"으로.
- "100% 안전", "평생 무료" 같은 **장담하는 말은 쓰지 않아요.** ("초대받은 가족만 볼 수 있어요", "지금은 무료예요")
- 모르는 사람에게 **문자 · 메일 · 쪽지로 광고를 보내지 않아요.** (아는 사람에게 소개하는 건 괜찮아요)
- 새 가족들의 문의(admin@dorantalk.com → 지메일)를 하루 한 번 확인해요.
