> 카페 · 당근 · 유튜브에 글을 올릴 때도 **보호자 계정**으로 해 주세요. (만 14세 미만은 가입이 안 되거나 보호자 동의가 필요해요)

     예전에는 가입 경로(`family`, `cafe` 등)가 사라져서 **"직접 · 기타"로 잡혔어요.** 이제는 그대로 남아요.

### 0-1. 데이터베이스 업데이트
아직 안 한 것만 **순서대로** 해요. (GitHub → **supabase → updates** → 파일 열기 → 📋 전체 복사 → Supabase **SQL Editor** → **+ New query** → 붙여넣기 → **Run**)
1. `v9_to_v10.sql` → "업데이트 완료! 버전 10" (13단계 · 아직 안 했다면)
2. `v10_to_v11.sql` → "업데이트 완료! 버전 11" (16단계 · 프로필 사진)
3. `v11_to_v12.sql` → "업데이트 완료! 버전 12" (이번 · 광고 성과)
4. 운영자 계정으로 로그인 → **내 정보 → 연결 점검 (운영자)** → "최신 버전(12)" 초록색

> 몇 번째 파일부터 해야 할지 모르겠으면 **연결 점검**을 먼저 열어 보세요. 실행할 파일을 순서대로 알려 줘요.

### 0-2. 가입 인증 메일 켜기 (아직 안 했다면)
모르는 사람이 가짜 이메일로 마구 가입하는 걸 막아요. **10단계 B-2** 를 따라 **Confirm email** 을 켜요.
> 메일(Resend) 무료 한도는 **하루 100통**이에요. 하루 가입이 50명을 넘기 시작하면 알려 주세요.

### 0-3. 가입 경로가 잘 잡히는지 시험
1. 휴대폰 **시크릿 창**에서 `https://www.dorantalk.com/welcome?from=test` → **무료로 시작하기** → 평소 안 쓰는 이메일로 가입
2. 운영자 계정 → **내 정보 → 광고 성과** → 가입 경로별에 **`test` 1명**이 보이면 성공
3. 시험한 계정은 **내 정보 → 회원 탈퇴** (탈퇴하면 숫자에서도 빠져요)

### 0-4. 카카오톡 안에서 열어 보기
1. 카카오톡 **나와의 채팅**에 `https://www.dorantalk.com/welcome?from=test2` 를 보내고 눌러 보기
2. 소개 화면 → **무료로 시작하기** → "카카오톡 안에서 열려 있어요" → **크롬/사파리로 열기**
3. 크롬 · 사파리에서 가입 화면이 열리면 가입 → 광고 성과에 **`test2`** 가 보이면 성공 → 시험 계정 탈퇴

## 1. 첫 주: 무료 홍보 (0원)
문구는 모두 [홍보 문구 모음](../marketing/promo-texts.md)에 있어요. 주소는 꼭 **채널별 주소**(`?from=…`)를 써요.

| 순서 | 할 일 | 문구 · 그림 | 주소 끝 |
|---|---|---|---|
| 1 | **가족 · 친구 단톡방**에 소개 (도란톡 → 그룹 → 멤버 탭 → **도란톡 가입 링크 보내기**) | 0번 핵심 한 줄 | `family` (자동) |
| 2 | **맘카페 · 지역 카페 홍보 게시판** (보호자 네이버 아이디) | 2번 | `cafe` |
| 3 | **당근 동네생활** (보호자 당근 계정) | 4번 | `daangn` |
| 4 | **유튜브 쇼츠** 올리기 (보호자 구글 계정) | 5-1번 영상 · 6번 제목 · 설명 | `youtube` |
| 5 | (선택) **네이버 블로그** | 3번 | `blog` |

**가장 효과가 큰 건 1번이에요.** 도란톡은 가족이 같이 써야 해서, 아는 사람이 "우리 이거 써" 하고 보내 주는 게 제일 잘 통해요.
친한 가족 3~5곳에 직접 보내 보세요.

### 유튜브 쇼츠 올리는 방법
1. 보호자 휴대폰에 영상 받기: GitHub → `marketing/video/dorantalk-ad-20s-9x16.mp4` → **Download raw file**(⬇)
2. 유튜브 앱 → 아래 **+** → **Shorts** → 오른쪽 아래 **갤러리** → 받은 영상 고르기
3. **사운드 추가**에서 무료 음악 고르기 (소리 없는 영상이에요) → **다음**
4. 제목: `가족 단톡방 대신 쓰는 가족 소식방 앱 (무료·광고 없음) #가족앱`
5. **시청자층**: **"아니요, 아동용이 아닙니다"** (어른에게 알리는 영상이에요)

## 2. 둘째 주: 네이버 검색 광고 테스트 (하루 5,000원 × 7일 = 35,000원)

**왜 네이버 검색 광고부터?** 인스타 계정이 없어도 되고, **"가족 앨범 앱"처럼 직접 찾는 사람**에게만 보여서 가입으로 잘 이어져요.
**누가 광고를 눌렀을 때만** 돈이 나가요. 보이기만 하고 안 누르면 0원이에요.

### 2-1. 광고 계정 만들기 (보호자, 약 15분)
1. **https://searchad.naver.com** → **신규가입** → **개인 광고주** → 보호자 네이버 아이디로 가입
2. **광고시스템** 들어가기

### 2-2. 캠페인 → 광고그룹 → 키워드 → 소재
1. **+ 새 캠페인** → **파워링크 유형**
   - 캠페인 이름: `도란톡 첫 광고` · **하루 예산: 5,000원**
2. **광고그룹 만들기**
   - 이름: `가족 앱 찾는 사람`
   - **URL**: `https://www.dorantalk.com` (사이트 등록이 처음이면 이 주소로 등록)
   - **기본 입찰가**: 처음엔 **낮게** 시작해요 (예: 200원). 3일 동안 노출이 거의 없으면 조금씩 올려요.
   - 매체: **모바일 · PC 모두** (도란톡은 휴대폰에서 쓰니까 모바일이 중요해요)
3. **키워드** (아래를 그대로 붙여넣기)
   ```
   가족앱
   가족 앱
   가족 사진 공유
   가족 사진 공유 앱
   가족 앨범 앱
   가족앨범
   가족 채팅 앱
   가족 소통 앱
   가족 소식
   부모님 사진 공유
   육아 사진 공유
   가족 단톡방
   ```
   - ⚠️ 다른 회사 앱 이름(상표)은 키워드로 넣지 않아요.
4. **소재 (광고 문구)**
   - 제목: `우리 가족만의 소식방 도란톡` (15자 안쪽이 넘치면 `우리 가족만의 소식방`)
   - 설명: `사진·소식·채팅을 가족끼리만. 큰 글씨와 쉬운 화면이라 부모님도 편해요.`
   - **연결 URL**: `https://www.dorantalk.com/welcome?from=naver_ad`
   - 표시 URL: `www.dorantalk.com`
5. **비즈머니 충전** → 보호자 카드 · 계좌로 **35,000원 정도** (7일치)
6. **검수**(검토)가 끝나면 광고가 시작돼요. 보통 1~2일 걸려요.
   - **검수에서 거절되면 그 사유를 캡처해서 보여 주세요.** 사이트에 필요한 걸 넣어 드릴게요.

> 도란톡에는 광고 추적 코드(네이버 · 구글 · 메타 픽셀 등)를 **넣지 않아요.** 아이들도 쓰는 앱이라서요.
> 그래서 효과는 **광고 성과 화면의 숫자**(`naver_ad`)로 봐요.

## 4. 7일 뒤: 계속할지 정하기

**계산해 보기**
- 가입 1명당 비용 = 광고비 ÷ 가입 수 (예: 35,000원 ÷ 7명 = 5,000원)
- 가족 1명당 비용 = 광고비 ÷ 가족과 연결 수 (예: 35,000원 ÷ 4명 ≈ 8,750원)

**이렇게 판단해요** (처음이라 정답은 없어요. 참고용이에요)

| 이런 결과면 | 이런 뜻이에요 | 이렇게 해요 |
|---|---|---|
| **노출이 거의 없음** (하루 수십 번 아래) | 입찰가가 낮거나, 그 키워드를 찾는 사람이 적어요 | 입찰가를 조금 올리거나 키워드를 더 넣어요 |
| 노출은 많은데 **클릭이 거의 없음** | 광고 문구가 눈에 안 띄어요 | 문구 모음 7번의 다른 제목 · 설명으로 바꿔요 |
| 클릭 **30번 이상**인데 가입 **0~1명** | 소개 화면에서 마음이 바뀌어요 | 소개 화면을 캡처해 보여 주세요. 같이 고쳐요 |
| 가입은 되는데 **가족과 연결 0** | 가입 뒤 가족 초대가 어려워요 | 알려 주세요. 초대 과정을 더 쉽게 고쳐요 |
| 가입 1명당 **5,000원 이하** + 가족과 연결이 **절반 이상** | 잘 되고 있어요 🎉 | 하루 1만 원으로 늘리거나, 유튜브 광고도 해 봐요 |

> 광고를 멈추고 싶으면: 네이버 광고 → 그 캠페인 → **OFF**. 남은 비즈머니는 다음에 다시 쓸 수 있어요.

## 6. (나중에) 인스타그램 계정이 생기면
- 프로필 링크 `…/welcome?from=insta`, 게시물 · 릴스 문구는 문구 모음 **5번 · 5-1번**
- 릴스 광고(**게시물 홍보하기**): 목표 **웹사이트 방문 늘리기** · 주소 `https://www.dorantalk.com/welcome?from=insta_ad`
  · 나이 30~55세 (꼭 만 18세 이상) · 하루 5,000원 × 7일 → 판단은 위 4번과 같아요

## 꼭 지킬 것
- 네이버 · 구글 광고에는 자동으로 **"광고" 표시**가 붙어요. 카페 · 당근 · 유튜브 글에서는 **직접 만든 서비스**라고 밝혀요. 이용자인 척 쓴 후기는 안 돼요.
- **어린이에게 광고하지 않아요.** 유튜브는 "아동용 아님", 광고 나이 타겟은 만 18세 이상으로.
- "100% 안전", "평생 무료" 같은 **장담하는 말은 쓰지 않아요.** ("초대받은 가족만 볼 수 있어요", "지금은 무료예요")
- 동의 없이 **문자 · 메일 · 쪽지로 광고를 보내지 않아요.**
- 새 가족들의 문의(admin@dorantalk.com → 지메일)를 하루 한 번 확인해요.
