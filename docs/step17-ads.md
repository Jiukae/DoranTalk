# 17단계 안내서 — 광고 시작하기 (첫 2주)

> 비용: 1주차 **0원** (무료 홍보) · 2주차 **35,000원** (인스타 광고 하루 5,000원 × 7일, 추천)
>
> 💳 **광고 계정 · 결제는 보호자(성인)가 해요.** 인스타그램 · 네이버 · 구글 광고는 모두 성인 계정과 결제 수단이 필요해요.
> 인스타그램 · 카페 · 당근 계정도 **보호자 계정**으로 해 주세요. (만 14세 미만은 가입이 안 되거나 보호자 동의가 필요해요)
> 홍보 글 · 영상 고르기와 매일 숫자 보기는 같이 하면 돼요.

## 이번에 앱에 새로 들어간 것
1. **광고 성과 화면 (운영자만)**: 운영자 계정(admin@dorantalk.com) → **내 정보 → 광고 성과 (운영자)**
   - **가입 경로별** 가입자 수 (오늘 · 7일 · 전체 · **가족과 연결**)
   - **날짜별 가입** (최근 14일) · **주마다 활동한 가족 수** (최근 8주)
   - 숫자만 보여요. 이름 · 이메일 · 글 · 사진 · 채팅 내용은 보지 않아요. (데이터베이스 버전 12)
   - 예전처럼 SQL 을 쓰지 않아도 휴대폰으로 바로 볼 수 있어요.
2. **인스타 · 카톡 안에서 열린 경우에도 가입 경로가 이어져요**
   - 인스타 광고를 누르면 **인스타 안의 브라우저**로 열려요. 가입하려고 "다른 브라우저로 열기"를 누르면
     예전에는 가입 경로(`insta_ad`)가 사라져서 **"직접 · 기타"로 잡혔어요.** 이제는 사파리 · 크롬으로 옮겨도 그대로 남아요.
   - 카카오톡으로 받은 가족 링크(`family`)도 마찬가지예요.

## 0. 광고 전에 꼭 (약 30분)

### 0-1. 데이터베이스 업데이트
아직 안 한 것만 **순서대로** 해요. (GitHub → **supabase → updates** → 파일 열기 → 📋 전체 복사 → Supabase **SQL Editor** → **+ New query** → 붙여넣기 → **Run**)
1. `v9_to_v10.sql` → "업데이트 완료! 버전 10" (13단계 · 아직 안 했다면)
2. `v10_to_v11.sql` → "업데이트 완료! 버전 11" (16단계 · 프로필 사진)
3. `v11_to_v12.sql` → "업데이트 완료! 버전 12" (이번 · 광고 성과)
4. 운영자 계정으로 로그인 → **내 정보 → 연결 점검 (운영자)** → "최신 버전(12)" 초록색

> 몇 번째 파일부터 해야 할지 모르겠으면 **연결 점검**을 먼저 열어 보세요. 실행할 파일을 순서대로 알려 줘요.

### 0-2. 가입 인증 메일 켜기 (아직 안 했다면)
모르는 사람이 가짜 이메일로 마구 가입하는 걸 막아요. **10단계 B-2** 를 따라 **Confirm email** 을 켜요.
> 메일(Resend) 무료 한도는 **하루 100통**이에요. 하루 가입이 50명을 넘기 시작하면 알려 주세요.

### 0-3. 가입 경로가 잘 잡히는지 시험
1. 휴대폰 **시크릿 창**에서 `https://www.dorantalk.com/welcome?from=test` → **무료로 시작하기** → 평소 안 쓰는 이메일로 가입
2. 운영자 계정 → **내 정보 → 광고 성과** → 가입 경로별에 **`test` 1명**이 보이면 성공
3. 시험한 계정은 **내 정보 → 회원 탈퇴** (탈퇴하면 숫자에서도 빠져요)

### 0-4. 인스타 안에서 열어 보기
1. 인스타 **DM** 으로 나(또는 가족)에게 `https://www.dorantalk.com/welcome?from=test2` 를 보내고 눌러 보기
2. 소개 화면 → **무료로 시작하기** → "다른 앱 안에서 열려 있어요" 안내 → ⋮ 메뉴 → **다른 브라우저로 열기**
3. 사파리 · 크롬에서 가입 화면이 열리면 가입 → 광고 성과에 **`test2`** 가 보이면 성공 → 시험 계정 탈퇴

## 1. 첫 주: 무료 홍보 (0원)
문구는 모두 [홍보 문구 모음](../marketing/promo-texts.md)에 있어요. 주소는 꼭 **채널별 주소**(`?from=…`)를 써요.

| 순서 | 할 일 | 문구 · 그림 | 주소 끝 |
|---|---|---|---|
| 1 | 가족 · 친구 단톡방에 소개 (그룹 → 멤버 탭 → **도란톡 가입 링크 보내기**) | 0번 핵심 한 줄 | `family` (자동) |
| 2 | 인스타 **프로페셔널 계정** 만들기 → 게시물 3개 + 릴스 1개 | 5번 · 5-1번 영상 | `insta` |
| 3 | 맘카페 · 지역 카페 **홍보 게시판** | 2번 | `cafe` |
| 4 | 당근 **동네생활** | 4번 | `daangn` |
| 5 | (선택) 네이버 블로그 | 3번 | `blog` |

- 인스타 프로페셔널 계정 만들기: 인스타 앱 → 프로필 → **≡** → **계정 유형 및 도구** → **프로페셔널 계정으로 전환** → **비즈니스** (무료)
- 프로필 링크: `https://www.dorantalk.com/welcome?from=insta`
- 2주차 광고에 쓸 **릴스**를 이때 올려 둬요: `marketing/video/dorantalk-ad-20s-9x16.mp4` + 인스타 앱의 **음악 추가** (소리 없는 영상이에요)

## 2. 둘째 주: 인스타 광고 테스트 (하루 5,000원 × 7일 = 35,000원)

**왜 인스타부터?** 광고 영상이 이미 있고, 부모님 세대가 많이 쓰고, 작은 돈으로 시작할 수 있고, 설정이 제일 쉬워요.

1. 인스타 앱 → 1주차에 올린 **릴스** → 아래 **게시물 홍보하기** (또는 **홍보하기**)
2. **목표**: **웹사이트 방문 늘리기**
   - 웹사이트: `https://www.dorantalk.com/welcome?from=insta_ad`
   - 버튼: **가입하기** (없으면 **더 알아보기**)
3. **타겟**: **직접 만들기**
   - 지역: **대한민국** · 나이: **30 ~ 55세** · 성별: 전체
   - 관심사: **육아**, **가족**, **부모** (검색해서 고르기)
   - ⚠️ 나이는 꼭 **만 18세 이상**으로 해요. 어린이에게 보이는 광고는 하지 않아요.
4. **예산 · 기간**: 하루 **5,000원** · **7일**
5. **결제 수단**: 보호자 카드 → **게시물 홍보하기**
6. 보통 하루 안에 검토가 끝나고 시작돼요. **거절되면 사유를 캡처해서 보여 주세요.** 같이 고쳐요.

> 광고 문구(캡션)가 필요하면 [문구 모음](../marketing/promo-texts.md) **7번**에서 골라요.
> 도란톡에는 광고 추적 코드(메타 픽셀 등)를 **넣지 않아요.** 아이들도 쓰는 앱이라서요. 그래서 효과는 **광고 성과 화면의 숫자**로 봐요.

## 3. 매일 1분: 숫자 보기
1. **인스타 앱** → 프로필 → **광고 도구**(또는 프로페셔널 대시보드 → 광고) → 진행 중인 광고
   → **지출 금액** · **링크 클릭(웹사이트 방문)** 보기
2. **도란톡** → 내 정보 → **광고 성과** → **인스타 · 페이스북 광고 (insta_ad)** 줄의 **오늘 · 7일 · 가족과 연결**
3. 아래처럼 적어 두면 비교하기 쉬워요. (메모장이나 종이에)

| 날짜 | 광고비 | 링크 클릭 | 가입 (insta_ad) | 가족과 연결 |
|---|---|---|---|---|
| 1일차 | 5,000원 | | | |
| 2일차 | | | | |

> **가족과 연결** = 가입한 뒤 다른 사람이 있는 그룹에 들어간 사람이에요. 도란톡은 가족이 함께 써야 의미가 있어서, **가입 수보다 이 숫자가 더 중요해요.**

## 4. 7일 뒤: 계속할지 정하기

**계산해 보기**
- 가입 1명당 비용 = 광고비 ÷ 가입 수 (예: 35,000원 ÷ 7명 = 5,000원)
- 가족 1명당 비용 = 광고비 ÷ 가족과 연결 수 (예: 35,000원 ÷ 4명 ≈ 8,750원)

**이렇게 판단해요** (처음이라 정답은 없어요. 참고용이에요)

| 이런 결과면 | 이런 뜻이에요 | 이렇게 해요 |
|---|---|---|
| 링크 클릭 **20번 미만** | 광고가 눈에 잘 안 띄어요 | 소재를 바꿔서 7일 더: 이미지 `insta-1-intro-1080.png` + 문구 7번의 2번 |
| 클릭 **50번 이상**인데 가입 **0~1명** | 소개 화면에서 마음이 바뀌어요 | 소개 화면을 캡처해 보여 주세요. 같이 고쳐요 |
| 가입은 되는데 **가족과 연결 0** | 가입 뒤 가족 초대가 어려워요 | 알려 주세요. 초대 과정을 더 쉽게 고쳐요 |
| 가입 1명당 **5,000원 이하** + 가족과 연결이 **절반 이상** | 잘 되고 있어요 🎉 | 하루 1만 원으로 늘리거나, 3주차에 네이버 검색 광고 추가 |

> 광고를 멈추고 싶으면: 인스타 앱 → 광고 도구 → 그 광고 → **일시 중지**. 남은 기간의 돈은 나가지 않아요.

  → 10단계 **F-2** · 문구 모음 **7번** (주소 끝 `naver_ad`)
- **구글 · 유튜브 광고**: 10단계 **F-3** (주소 끝 `google_ad`)
- 광고 성과 화면에서 **가족과 연결**이 많이 나온 곳에 예산을 옮겨요.
- 4주가 지나면 **주마다 가족 활동** 숫자로 "가입한 가족이 계속 쓰는지"도 봐요. (10단계 D-2)

## 꼭 지킬 것
- **인스타 광고는 자동으로 "광고" 표시**가 붙어요. 카페 · 당근 글에서는 **직접 만든 서비스**라고 밝혀요. 이용자인 척 쓴 후기는 안 돼요.
- **어린이에게 광고하지 않아요.** 나이 타겟은 만 18세 이상으로.
- "100% 안전", "평생 무료" 같은 **장담하는 말은 쓰지 않아요.** ("초대받은 가족만 볼 수 있어요", "지금은 무료예요")
- 동의 없이 **문자 · 메일 · 쪽지로 광고를 보내지 않아요.**
- 새 가족들의 문의(admin@dorantalk.com → 지메일)를 하루 한 번 확인해요.
