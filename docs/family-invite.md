# 가족에게 보낼 초대 문구

카카오톡 가족 대화방에 아래 문구를 그대로 복사해서 보내세요.
(앱의 **가족** 탭 → **📤 가족에게 도란톡 링크 보내기** 버튼을 눌러도 같은 문구가 보내져요)

---

```
우리 가족 소식방 도란톡에 초대할게요! 😊

① 아래 링크를 눌러 회원가입해 주세요
   https://dorantalk.com

② 가입할 때 정한 '아이디'를 저에게 알려 주세요
   → 제가 앱에서 초대하면, 홈 화면에 '받은 초대'가 떠요. '수락하기'를 눌러 주세요!

📱 카카오톡 안에서 열리면 위쪽의 '크롬/사파리로 열기' 버튼을 눌러 주세요.
📱 앱처럼 쓰려면: 로그인 후 '내 정보 → 사용 방법'을 보고 홈 화면에 추가해 주세요.
```

---

## 부모님께 드리는 짧은 안내 (출력하거나 사진 찍어 보내기)

```
[도란톡 쓰는 법]

▶ 앱 열기: 휴대폰 화면의 주황색 집 모양 '도란톡' 아이콘

▶ 소식 보기·쓰기: 아래 '소식' 
   - 위의 '눌러서 소식 쓰기' → 글 쓰고 📷로 사진 넣고 → '올리기'
   - 🤍 누르면 좋아요, '댓글 쓰기'로 댓글

▶ 채팅: 아래 '채팅'
   - 글 쓰고 '보내기', 📷로 사진 보내기
   - 내 말 옆 주황 숫자 = 아직 안 읽은 가족 수

▶ 모르겠을 때: '내 정보' → '사용 방법'
```
