# 8단계 안내서 — 개인정보처리방침 · 이용약관 · 회원 탈퇴 · 문의 메일

> 소요 시간: 약 25분 (메일 설정이 퍼지는 기다림 제외) · 비용: 무료
>
> 화면 이름은 가끔 바뀌어요. 비슷한 메뉴를 찾거나, 막히면 화면을 캡처해 보여 주세요.

다른 가족들도 도란톡을 쓰게 하려면 법으로 꼭 갖춰야 하는 것들이 있어요. 이번 단계에서 앱에 넣은 것:

- **개인정보처리방침** (`#/privacy`) — 무엇을 모으고, 어디에 맡기고, 언제 지우는지. 보호책임자: **한지욱**
- **이용약관** (`#/terms`) — 서비스 규칙 (제1조~제13조)
- **가입할 때 동의 받기** — [필수] 만 14세 이상 · [필수] 이용약관 · [필수] 개인정보 수집·이용 (모두 체크해야 가입 가능)
- **회원 탈퇴** (`#/me/delete`) — 내 계정, 글, 사진, 댓글, 하트, 채팅을 바로 삭제
- **문의 메일** — **admin@dorantalk.com** 으로 오는 메일을 내 메일함으로 전달
- 로그인 화면, 내 정보, 사용 방법 아래에 **이용약관 · 개인정보처리방침 · 문의** 링크

| 순서 | 할 일 | 걸리는 시간 |
|---|---|---|
| A | 데이터베이스 업데이트 (회원 탈퇴 기능) | 3분 |
| B | admin@dorantalk.com 으로 메일 받기 (ImprovMX) | 15분 + 기다림 |

| D | 확인하기 | 5분 |

> 화면(앱)은 이미 dorantalk.com 에 자동으로 올라갔어요. **A를 하기 전까지는 회원 탈퇴만 오류가 나요.** 먼저 A부터 해 주세요.

## A. 데이터베이스 업데이트 (버전 4 → 5)

회원 탈퇴할 때 필요한 기능을 데이터베이스에 넣어요.
- 탈퇴한 사람이 올린 사진 파일 찾아서 지우기
- 계정과 그 사람의 글, 댓글, 하트, 채팅 함께 지우기
- 혼자 남은 그룹은 지우기
- 방장이 나가면 가장 먼저 들어온 가족에게 방장 넘기기

1. GitHub에서 **supabase** 폴더 → **updates** 폴더 → **v4_to_v5.sql** 을 엽니다.
2. 오른쪽 위 **복사 버튼**(네모 두 개 겹친 모양 📋)을 눌러 **전체**를 복사해요.
3. **Supabase** → 왼쪽 **SQL Editor** → **+ New query**(새 탭)
4. 빈 칸에 붙여넣고 오른쪽 아래 **Run**
   - 글자 일부가 파랗게 선택돼 있으면 그 부분만 실행돼서 오류가 나요. **빈 곳을 한 번 클릭해 선택을 풀고** Run 하세요.
5. 아래 결과에 **"업데이트 완료! 버전 5"** 가 나오면 성공
6. 휴대폰에서 **https://dorantalk.com/#/check** → **"데이터베이스 최신 버전 — 최신 버전(5)이에요"** 가 초록색인지 확인

> "Potential issue detected… destructive operation" 같은 경고 창이 뜨면 **Run this query** 를 눌러도 괜찮아요.
> (같은 이름의 설정을 새로 만들기 전에 지우는 것뿐이고, 가족 글이나 사진은 지우지 않아요.)

## B. admin@dorantalk.com 으로 메일 받기 (ImprovMX, 무료)

지금은 admin@dorantalk.com 이 **보내기**(비밀번호 찾기 메일)만 돼요.
개인정보처리방침에 문의 주소로 적었으니 **받기**도 되게 할게요.
**ImprovMX**는 admin@dorantalk.com 으로 온 메일을 **내 지메일(또는 네이버 메일)로 그대로 전달**해 주는 무료 서비스예요.

### B-1. ImprovMX 가입
1. **https://improvmx.com** 에 들어가요.
2. 첫 화면 입력 칸 두 개에
   - 왼쪽: `dorantalk.com`
   - 오른쪽: **메일을 받을 내 메일 주소** (평소 쓰는 지메일 등)
3. **Create a free alias** (또는 비슷한 초록 버튼) → 가입(이메일 확인 메일이 오면 링크 누르기)
4. 대시보드에 dorantalk.com 이 생기고, 빨간 글씨로 **"Email forwarding needs setup"** 같은 안내와 **MX / TXT 값**이 보여요. 이 화면은 열어 두세요.

### B-2. 받을 주소(별칭) 정하기
1. dorantalk.com 카드 아래 **Aliases** 에서
   - 기본으로 `*`(모든 주소) → 내 메일 이 있으면 그대로 둬도 돼요 (아무개@dorantalk.com 도 다 받아요)
   - 또는 **Add new alias** → 왼쪽 `admin` · 오른쪽 내 메일 → **Add**
2. 이게 끝이에요. 다음은 가비아에 "메일은 ImprovMX로 보내 주세요" 라고 적는 단계예요.

### B-3. 가비아 DNS에 3줄 추가
1. **My가비아 → 서비스 관리 → 도메인** → dorantalk.com 옆 **관리** → **DNS 정보** → **DNS 관리툴** → **설정**
2. ⚠️ **이미 있는 줄은 하나도 지우지 마세요.**
   (A `@`, CNAME `www`, Resend 것 `send` · `resend._domainkey` · `_dmarc` 는 그대로!)
3. **레코드 추가**로 아래 3줄을 넣고 **저장**

   | 타입 | 호스트 | 값/위치 | 우선순위 | TTL |
   |---|---|---|---|---|
   | **MX** | `@` | `mx1.improvmx.com.` | `10` | 기본값 |
   | **MX** | `@` | `mx2.improvmx.com.` | `20` | 기본값 |
   | **TXT** | `@` | `v=spf1 include:spf.improvmx.com ~all` | (없음) | 기본값 |

   - MX 값 끝의 점(`.`)은 가비아 화면이 요구할 때만 붙이세요. (7단계 때와 같아요)
   - **값이 ImprovMX 화면과 다르면 ImprovMX 화면을 따르세요.**
   - 호스트 `@` 에 **`v=spf1` 로 시작하는 TXT가 이미 있다면** 새로 만들지 말고 화면을 캡처해서 보여 주세요. (한 도메인에 SPF는 한 줄만 있어야 해요. 합쳐 드릴게요)

### B-4. 기다리기 → 확인
1. ImprovMX 대시보드에서 **Check again**(또는 새로고침). 보통 **10분~1시간**, 길면 하루.
2. 빨간 안내가 사라지고 초록색 **"Email forwarding active"** 가 되면 성공
3. **다른 메일 주소**(예: 네이버 메일, 가족 메일)에서 **admin@dorantalk.com** 으로 아무 메일이나 보내 보세요.
   → 몇 분 안에 내 메일함에 오면 완료 🎉 (안 보이면 스팸함도 확인)
   - 내 지메일에서 내 지메일로 전달되는 경우, 지메일이 "이미 있는 메일"로 보고 받은편지함에 안 보여 줄 때가 있어요. 그래서 **다른 주소에서** 보내 보는 게 정확해요.

> 비밀번호 찾기 메일(보내기)은 Resend가, 문의 메일(받기)은 ImprovMX가 맡아요. 서로 다른 줄을 쓰니까 둘 다 잘 돼요.

### B-5. (선택) 답장도 admin@dorantalk.com 으로 보내기
그냥 내 지메일로 답장해도 괜찮아요. 꼭 admin@ 주소로 답장하고 싶을 때만 하세요.
> Outlook(윈도우)에서 받고 답장하고 싶다면 → [Outlook 연결 안내서](outlook-mail.md)

1. **Resend** → 왼쪽 **API Keys** → **Create API Key** → 이름 `gmail` · 권한 **Sending access** · 도메인 dorantalk.com → **Add** → 나온 키(`re_`로 시작)를 복사
   - 이 키는 비밀번호예요. **어디에도 붙여넣지 말고** 아래 지메일 칸에만 넣으세요.
2. **지메일(컴퓨터)** → 오른쪽 위 ⚙️ → **모든 설정 보기** → **계정 및 가져오기** → **다른 주소에서 메일 보내기: 다른 이메일 주소 추가**
3. 이름 `도란톡`, 이메일 `admin@dorantalk.com`, **별칭으로 처리** 체크 해제 → **다음 단계**
4. SMTP 서버 `smtp.resend.com` · 포트 `587` · 사용자 이름 `resend` · 비밀번호 = 1번에서 복사한 키 · **TLS 보안 연결** → **계정 추가**
5. 확인 메일이 admin@dorantalk.com 으로 가고, B에서 설정한 덕분에 **내 지메일로 전달돼요** → 메일 안의 확인 링크 누르기
6. 이제 지메일에서 메일을 쓸 때 **보낸 사람**을 admin@dorantalk.com 으로 고를 수 있어요.

## C. 방침에 적힌 서버 지역이 맞는지 확인

개인정보처리방침 6번에 **"개인정보가 어느 나라에 보관되는지"** 를 적었어요. 안내서대로 했다면 아래와 같아요. 실제 설정과 같은지만 확인해 주세요.

| 업체 | 방침에 적힌 위치 | 확인하는 곳 |
|---|---|---|
| Supabase | 대한민국(서울) | Supabase → 왼쪽 아래 ⚙️ **Project Settings** → **General** → **Region** 이 `Northeast Asia (Seoul)` / `ap-northeast-2` |
| Resend | 일본(도쿄) | Resend → **Domains** → dorantalk.com → **Region** 이 `Tokyo` / `ap-northeast-1` |

다르게 나오면 **화면을 보여 주세요.** 방침의 글자만 고치면 돼요.

## D. 확인하기

휴대폰으로 https://dorantalk.com 에서:

- [ ] **처음 한 번 "약관에 동의해 주세요" 화면이 떠요.** (이미 가입한 가족 모두 한 번씩)
      → **모두 동의해요** 체크 → **동의하고 계속하기** → 원래 쓰던 화면으로 돌아가요
- [ ] 로그인 화면 맨 아래 **이용약관 · 개인정보처리방침 · 문의** 링크가 열려요
- [ ] **개인정보처리방침**에 보호책임자 **한지욱**, 문의 **admin@dorantalk.com** 이 보여요
- [ ] (로그아웃 후) **회원가입** 화면에 **약관 동의** 칸이 있고, 체크하지 않으면 가입이 안 돼요
- [ ] **내 정보** 맨 아래에 **회원 탈퇴** 가 있어요
      (진짜로 누르면 내 계정이 지워져요! 확인은 **화면이 열리는 것까지만** 하고 **탈퇴하지 않고 돌아가기**)
- [ ] `#/check` 가 모두 초록색, **최신 버전(5)**

> 회원 탈퇴를 직접 시험해 보고 싶다면, 다른 이메일로 **시험용 계정**을 하나 만들어서 그 계정으로 해 보세요.

## 알아 두면 좋은 것

- **가족들에게 미리 한마디:** "앱을 열면 약관 동의 화면이 한 번 나와요. '모두 동의해요' 누르고 계속하면 돼요."
- **약관이나 방침 내용을 바꾸고 싶을 때:** 말씀만 해 주세요. 고친 뒤에는 회원들이 바뀐 내용에 **다시 동의하는 화면**이 한 번 더 나와요.
- **만 14세 미만 가족(아이)** 은 가입할 수 없어요. 법에서 만 14세 미만은 **보호자 동의 절차**가 따로 필요하기 때문이에요. 꼭 필요해지면 말씀해 주세요.
- **누가 "내 정보 지워 주세요" 라고 메일을 보내면:** 먼저 앱의 **내 정보 → 회원 탈퇴**를 안내해 주세요. 직접 못 하는 상황이면 Supabase → **Authentication → Users** 에서 그 이메일 옆 **⋯ → Delete user** 로 지울 수 있어요. (이때는 사진 파일이 남으니, 저에게 알려 주시면 정리 방법을 알려 드릴게요)
- **문의 메일 답장:** 법에서 "지체 없이" 처리하라고 해요. 보통 **10일 안에** 답하면 돼요.
