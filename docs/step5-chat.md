# 5단계 안내서 — 실시간 채팅

> 소요 시간: 약 10분 · 준비물: 휴대폰 + 두 번째 계정(같은 그룹)
> **이번 단계는 Supabase에서 할 일(SQL 실행)이 없어요!** 1단계에서 채팅용 표와 보안 규칙을 미리 만들어 두었거든요.

5단계에서 만든 것 (그룹 화면 아래 **채팅** 탭)

- **실시간 메시지**: 가족이 보낸 메시지가 **새로고침 없이 바로** 떠요
- **사진 보내기**: 입력칸 왼쪽 **📷** → 앨범에서 고르기 (한 번에 10장까지, 자동으로 줄여서 보내요)
- **안 읽은 메시지 표시** (카카오톡처럼)
  - 메시지 옆 주황색 숫자 = **아직 그 메시지를 안 읽은 가족 수**. 모두 읽으면 숫자가 사라져요
  - 채팅방 밖에 있으면 아래 **채팅** 탭에 빨간 숫자, 홈 화면 그룹 옆에 **💬 숫자**
  - 💬 숫자가 있는 그룹을 누르면 바로 채팅방으로 들어가요
- 날짜가 바뀌면 "2026년 10월 13일 화요일" 처럼 날짜 줄이 생겨요
- 휴대폰이 잠들었다 깨어나도, 그동안 온 메시지를 자동으로 가져와요
- 인터넷이 끊겨 못 보낸 메시지는 **전송 실패 → 다시 보내기**
- 맨 위 **이전 대화 더 보기** 로 예전 대화 보기
- 휴대폰: 입력하는 동안 아래 탭이 잠깐 숨어요(키보드 공간). 메시지 쪽을 한 번 누르면 다시 보여요
- 컴퓨터: **Enter = 보내기**, **Shift + Enter = 줄바꿈**

## A. 확인 전에: 연결 점검

휴대폰에서 **https://talkfeed.netlify.app/#/check** 를 열어 주세요.

  (예전 버전이 보이면 창을 닫고 새로 열기)
- 새로 생긴 **"실시간 연결 (채팅)"** 까지 **5개 모두 초록색 ✓** 이면 준비 완료

## B. 휴대폰으로 확인하기 (두 사람이 동시에)

**나** = 내 휴대폰, **상대** = 같은 그룹의 두 번째 계정 (가족 휴대폰 또는 컴퓨터 시크릿 창)

| # | 누가 | 해 볼 것 | 이렇게 되면 정상 |
|---|---|---|---|
| 1 | 둘 다 | 같은 그룹 → **채팅** 탭 열어 두기 | "가족 채팅방이에요" 안내 |
| 2 | 나 | 메시지 입력 → **보내기** | 내 메시지가 오른쪽 주황색 말풍선으로. 옆에 **1** |
| 3 | 상대 | (아무것도 누르지 않고) 화면 보기 | **새로고침 없이** 내 메시지가 왼쪽에 이름과 함께 떠요 |
| 4 | 나 | 내 메시지 옆 숫자 보기 | 상대가 봤으니 **1 이 사라져요** |
| 5 | 상대 | 답장 보내기 | 내 화면에 바로 떠요 |
| 6 | 상대 | **소식** 탭으로 이동 | |
| 7 | 나 | 메시지 2개 보내기 | 내 메시지 옆에 **1** 이 남아 있어요 |
| 8 | 상대 | 아래 **채팅** 탭 | 빨간 **2** 표시 |
| 9 | 상대 | 위 **‹ 목록** 눌러 홈으로 | 그룹 옆에 **💬 2** |
| 10 | 상대 | 그 그룹 누르기 | 바로 채팅방이 열리고, 내 화면의 **1** 이 사라져요 |
| 11 | 나 | **📷** → 사진 2장 고르기 | 사진이 보내지고 상대 화면에도 떠요. 사진을 누르면 크게 보여요 |
| 12 | 나 | 휴대폰 화면을 끄고 1분 뒤 켜기 (그사이 상대가 메시지 보내기) | 앱으로 돌아오면 놓친 메시지가 보여요 |

**Supabase에서도 확인해 보기 (선택)**
- **Table Editor** → **messages**: 보낸 메시지 / **chat_reads**: 가족별로 어디까지 읽었는지
- **Storage** → **family-photos** → 그룹 ID 폴더 → **chat**: 채팅으로 보낸 사진

문제가 있으면 **몇 번에서 어떤 글자가 떴는지** 알려 주시거나 화면을 캡처해 주세요.
