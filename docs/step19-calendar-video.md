# 19단계 안내서 — 안부 인사 · 동영상 · 가족 달력 (생신 알림)

> 소요 시간: 약 10분 · 비용: 무료
> 할 일은 **두 가지**예요: ① 데이터베이스 업데이트 ② 알림 서버(push) 다시 올리기

## 바뀐 것
1. **안부 인사 10개** (소식 탭 맨 위)
   - `잘 지내요? 😊` `잘 지내요! 👋` `밥 먹었어요? 🍚` `보고 싶어요 💛` `건강 챙기세요 🍀`
     `오늘도 힘내요 💪` `다음에 만나요 🤗` `고마워요 🙏` `사랑해요 ❤️` `잘 자요 🌙`
   - 한 번 누르면 **채팅으로 보내지고** 가족에게 알림이 가요. 글자 치기 어려운 할머니 · 할아버지도 쉽게 인사해요.
   - 아래에 **"오늘 안부를 보낸 가족: 엄마 · 할머니"** 처럼 오늘 누가 인사했는지 보여요.
   - 채팅방에서는 안부 말풍선이 조금 더 크고 따뜻한 색으로 보여요.
2. **동영상 올리기 — 누구나 무료** (프리미엄 아니어도 돼요)
   - 소식 쓰기: **사진 · 동영상 추가** / 채팅: 사진 버튼에서 동영상도 골라요.
   - 사진 탭에도 함께 모이고, ▶ 표시를 누르면 바로 재생돼요.
   - 한 개 **50MB 까지** (휴대폰 동영상 보통 30초~1분), 한 사람 **하루 10개까지**.
     더 길면 휴대폰 사진 앱에서 앞뒤를 잘라서 올려요.
3. **가족 달력** — 그룹 아래 탭이 **소식 · 채팅 · 사진 · 달력 · 멤버** 5개가 됐어요.
   - **생신 🎂 · 기일 🕯️ · 기념일 💐 · 일정 📌** 을 넣어요.
   - **양력 / 음력** 둘 다 돼요. 음력은 **윤달**도 고를 수 있어요.
   - **매년**(생신 · 기일 · 기념일) 또는 **한 번만**(가족 여행 · 모임 같은 일정).
   - 달력에 그림이 찍히고, 아래 **다가오는 일정**에 `오늘` `D-1` `D-12` 처럼 보여요.
   - 홈 화면에도 **다가오는 가족 일정** (30일 안, 모든 그룹)이 보여요.
   - 지우기는 **만든 사람이나 방장**만 할 수 있어요. (실수로 할머니 생신이 지워지지 않게)
4. **생신 알림** — 일정 **하루 전**과 **당일**에 가족에게 알림이 가요.
   예: `시골집 · 가족 달력` / `내일 · 할머니 생신 🎂 (음력 3월 5일)`
5. 이용약관(제6조) · 개인정보처리방침 · 도움말에 안부 · 동영상 · 가족 달력을 적었어요.

## 할 일 1: 데이터베이스 업데이트 (버전 13 → 14)
1. GitHub → **supabase → updates → v13_to_v14.sql** → 📋 전체 복사
   (아직 안 한 앞 버전 파일이 있으면 그것부터 차례로. 운영자 **연결 점검**이 순서를 알려 줘요)
2. Supabase → **SQL Editor** → **+ New query** → 붙여넣기 → **Run**
3. **"업데이트 완료! 버전 14"** 가 보이면 성공 → 연결 점검 "최신 버전(14)"

> 업데이트 전에도 앱은 그대로 돼요. 안부 인사는 보통 메시지로 가고, 달력 탭에는 "가족 달력은 곧 열려요"가 보여요.
> 동영상은 업데이트 **후에** 올릴 수 있어요. (사진 창고가 동영상을 받도록 바꾸는 게 이 업데이트 안에 있어요)

## 할 일 2: 알림 서버(push) 다시 올리기 ⚠️ 꼭 해 주세요
알림 서버에 **"달력 알림"** 종류가 새로 생겼어요. 이걸 안 하면 달력은 되는데 **생신 알림만 안 가요.**
(9단계 B에서 처음 올렸던 것과 같은 방법이에요. 컴퓨터에서 하는 걸 추천해요)

1. GitHub → **supabase → functions → push → index.ts** → 오른쪽 위 **복사 버튼**(📋)으로 **전체** 복사
2. **Supabase** → 왼쪽 메뉴 **Edge Functions** (번개 모양 ⚡) → 목록에서 **push** 누르기
3. 위쪽 탭 중 **Code** 누르기 → 편집기 안의 글을 **모두 지우고**(Ctrl+A → Delete) 복사한 코드 **붙여넣기**
4. 오른쪽 아래 **Deploy updates** (또는 **Deploy**) → 1분쯤 기다리면 "Successfully deployed"
5. **Details** 탭 → **Enforce JWT Verification**(Verify JWT) 가 **꺼져(OFF) 있는지** 한 번 더 확인
   - 켜져 있으면 끄고 **Save** (9단계 B-3 과 같아요)

> 다른 설정(VAPID 열쇠 등)은 그대로 두면 돼요. 코드만 바꿔요.

## 생신 알림은 이렇게 가요
- 도란톡에는 정해진 시간에 울리는 "알람 시계" 서버가 따로 없어요. 그래서
  **가족 중 누군가 그날 처음 도란톡(홈 화면)을 열 때** 그날 보낼 알림을 가족 모두에게 보내요.
  - 하루 전 · 당일 **한 번씩만** 가요. 여러 명이 열어도 두 번 가지 않아요.
  - 앱을 연 사람은 홈 화면 **다가오는 가족 일정**에서 바로 보니까, 그 사람에게는 알림을 보내지 않아요.
  - 가족이 여럿이면 보통 아침에 누군가 열어서 일찍 가요. 아무도 안 열면 늦게 갈 수 있어요.
- 알림은 **알림을 켠 가족**만 받아요. (9단계 · 15단계 안드로이드 앱)
- 나중에 "매일 아침 9시에 딱 보내기"를 원하면 Supabase **Cron** 으로 바꿀 수 있어요. (원하면 말해 줘요)

## 음력은 이렇게 계산해요
- 음력 생신은 해마다 양력 날짜가 바뀌어요. 도란톡이 **한국천문연구원 음력 기준**으로 **2050년까지** 알아서 계산해요.
- 그 해에 **윤달이 없으면 평달**로, 그 달이 **29일까지만 있으면 30일은 29일**로 셈해요. (생신 · 기일을 챙길 때 흔히 쓰는 방법)
- 넣을 때 아래에 **"다음은 11월 8일 (일) (D-1)"** 처럼 미리 보여 줘요. 맞는지 한 번 확인하고 넣으면 돼요.

## 알아 둘 것
- **저장 공간**: 동영상은 사진보다 **10~20배** 커요. Supabase 무료는 사진 · 동영상 합쳐서 **1GB** 예요.
  (1분 동영상 약 30~60MB → 20~30개면 1GB 가 찰 수 있어요)
  동영상을 **볼 때**도 Supabase 무료의 **보기(내려받기) 한 달 5GB** 를 써요. (50MB 동영상을 100번 보면 5GB)
  한 달에 한 번 Supabase **Usage** 에서 **Storage** 와 **Egress**(보기) 를 봐 주세요. (10단계 G)
  80%가 넘으면 알려 주세요. Supabase **Pro**(월 $25, 저장 100GB · 보기 250GB)로 올리거나, 그때 동영상을 프리미엄으로 옮기는 걸 같이 생각해요.
- **아이폰 동영상이 안 보일 때**: 아이폰은 기본으로 "HEVC" 형식으로 찍어서, 어떤 안드로이드 · 컴퓨터에서는 재생이 안 될 수 있어요.
  아이폰 쓰는 가족은 **설정 → 카메라 → 포맷 → "높은 호환성"** 으로 바꿔 두면 모든 휴대폰에서 잘 보여요.
- 동영상도 사진처럼 **같은 그룹 가족만** 볼 수 있어요. (보안 규칙 그대로)
