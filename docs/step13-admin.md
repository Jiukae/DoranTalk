# 13단계 안내서 — 연결 점검은 운영자만 · 운영자 이름 보호

> 소요 시간: 약 3분 · 비용: 무료

## 바뀐 것
1. **연결 점검(`#/check`)은 운영자 계정만** 열 수 있어요.
   - 운영자 = **이메일 `admin@dorantalk.com` 으로 로그인한 계정** (아이디 · 닉네임 "도란톡")
   - 운영자 확인은 **로그인 이메일**로 해요. 아이디 · 닉네임은 바꿀 수 있어서 기준으로 쓰지 않아요.
   - 다른 회원이 열면 "운영자만 볼 수 있는 화면이에요"가 나오고, 로그아웃 상태면 로그인 화면으로 가요.
   - 운영자의 **내 정보 → 도움말 · 안내**에 **"연결 점검 (운영자)"** 줄이 생겨요. (다른 회원에게는 안 보여요)
   - 앱 설정 파일에 문제가 있을 때 자동으로 뜨는 점검 화면은 그대로예요. (그때는 로그인 자체가 안 되니까)
2. **운영자 이름 보호 (데이터베이스 버전 10)**
   - "도란톡" · "dorantalk" 이 들어간 이름, "관리자" · "운영자" · "운영진" · "admin" 은 **운영자만** 아이디 · 닉네임으로 쓸 수 있어요.
   - 닉네임은 겹칠 수 있어서, 이게 없으면 누구나 "도란톡"이라고 이름을 짓고 운영자인 척 초대를 보낼 수 있어요.

2. Supabase → **SQL Editor** → **+ New query** → 붙여넣기 → **Run**
3. 결과 표가 2개 나와요.
   - **결과 1**: 운영자가 아닌데 운영자 이름을 쓰고 있는 회원 목록 → **"0 rows"(비어 있음)면 정상**
     - 누가 나오면 캡처해서 보여 주세요. (그 회원에게 이름을 바꿔 달라고 하거나, 함께 정리해요)
   - **결과 2**: **"업데이트 완료! 버전 10"** 이 보이면 성공
4. **운영자 계정(admin@dorantalk.com)으로 로그인**한 상태에서 **https://dorantalk.com/#/check** → "최신 버전(10)" 확인
