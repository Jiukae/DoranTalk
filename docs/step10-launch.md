# 10단계 안내서 — 다른 가족들에게 공개하고 홍보하기

> 소요 시간: 필수(A~D) 약 20분 · 비용: 무료 (유료 광고비는 직접 정해요)
>
> 화면 이름은 가끔 바뀌어요. 비슷한 메뉴를 찾거나, 막히면 화면을 캡처해 보여 주세요.

이번 단계에서 앱에 새로 들어간 것:
- **소개 화면** `https://dorantalk.com/welcome` — 처음 온 사람이 "이게 뭐지?" 하고 바로 알 수 있는 화면
  - 처음 온 사람이 `dorantalk.com` 만 입력하면 소개 화면부터 보여요. (이미 쓰던 휴대폰 · 홈 화면 앱 · 로그인한 사람은 그대로 앱이 열려요)
- **링크 미리보기** — 카카오톡 · 인스타 · 페이스북에 주소를 붙이면 그림과 제목이 나와요
- **가입 경로 기록** — 홍보 주소 끝의 `?from=insta` 같은 표시로 **어디서 보고 가입했는지** 숫자로 볼 수 있어요 (가입 경로 한 단어만, 개인정보처리방침에도 적어 두었어요)
- **장난 방지 제한 (DB 버전 7)** — 모르는 사람이 초대를 마구 보내거나 그룹을 마구 만들지 못하게
  - 그룹 만들기: 하루 5개, 한 사람이 들어가 있는 그룹 20개까지
  - 초대: 하루 30번, 거절당하면 3일 뒤에 다시, 대기 중 초대 20개, 한 그룹 50명까지
- **홍보 이미지 · 문구** — [`marketing/`](../marketing) 폴더 ([문구 모음](../marketing/promo-texts.md))

## A. 데이터베이스 업데이트 (버전 6 → 7)

1. GitHub에서 **supabase** → **updates** → **v6_to_v7.sql** 을 엽니다.
2. 오른쪽 위 **복사 버튼**(네모 두 개 📋)을 눌러 **전체** 복사
3. **Supabase** → 왼쪽 **SQL Editor** → **+ New query** → 붙여넣기 → **Run**
   - "destructive operation" 경고 창이 뜨면 **Run this query** (가족 데이터는 지우지 않아요)
4. 결과에 **"업데이트 완료! 버전 7"** 이 나오면 성공
5. **https://dorantalk.com/#/check** → "데이터베이스 최신 버전 — 최신 버전(7)" 초록색 확인

## B. 로그인 보안 설정 확인

### B-1. 주소 설정 확인 (이미 7단계에서 했어요 — 확인만)
1. Supabase → 왼쪽 **Authentication** → **URL Configuration**
2. **Site URL** 이 `https://dorantalk.com` 인지
3. **Redirect URLs** 에 `https://dorantalk.com/**` 가 있는지

### B-2. 가입 인증 메일 켜기 (추천)
지금은 2단계에서 가족이 쉽게 가입하도록 **이메일 인증을 꺼 두었어요.**
모르는 사람이 가입하기 시작하면 **가짜 이메일로 마구 가입**하는 걸 막기 위해 켜 두는 게 좋아요.
켜면 가입할 때 **"메일함을 확인해 주세요"** 화면이 나오고, 메일의 버튼을 누르면 가입이 끝나요. (앱은 이미 준비돼 있어요)
이미 가입한 가족에게는 아무 영향이 없어요.

1. Supabase → **Authentication** → **Sign In / Providers** (예전 이름: Providers → Email)
2. **Confirm email** 스위치를 **켜기(초록색)** → **Save changes**
3. **Authentication** → **Emails** → **Templates** 탭 → **Confirm signup**
   - **Subject**: `[도란톡] 가입을 마무리해 주세요`
   - **Body**: 내용을 모두 지우고 아래를 붙여넣기 → **Save changes**
   ```html
   <h2>도란톡에 오신 것을 환영해요</h2>
   <p>아래 버튼을 누르면 가입이 끝나고 바로 도란톡이 열려요.</p>
   <p><a href="{{ .ConfirmationURL }}" style="display:inline-block;padding:14px 24px;background:#c9581f;color:#ffffff;border-radius:12px;text-decoration:none;font-weight:bold;font-size:18px">가입 마무리하기</a></p>
   <p>직접 가입하지 않았다면 이 메일은 무시하셔도 괜찮아요.</p>
   ```
4. **시험해 보기**: 휴대폰의 **시크릿 창**(크롬) 또는 **개인정보 보호 브라우징**(사파리)에서
   `https://dorantalk.com/#/signup` → **평소 안 쓰는 다른 이메일**로 가입
   → "메일함을 확인해 주세요" 화면 → 메일의 **가입 마무리하기** → 도란톡 홈이 열리면 성공
   - 시험한 계정은 **내 정보 → 회원 탈퇴**로 지우면 돼요.

> 메일 보내기(Resend) 무료 한도는 **하루 100통 · 한 달 3,000통**이에요. (가입 인증 + 비밀번호 찾기 합쳐서)
> 하루 가입이 수십 명을 넘기 시작하면 알려 주세요. 한도를 보는 곳: **resend.com → Usage**

### B-3. 로그인 시도 제한 확인 (확인만)
1. Supabase → **Authentication** → **Rate Limits**
2. 기본값 그대로 두면 돼요. 같은 곳에서 짧은 시간에 가입 · 로그인을 너무 많이 하면 Supabase가 잠시 막아 줘요.

## C. 소개 화면 · 링크 미리보기 확인

1. 휴대폰에서 **https://dorantalk.com/welcome** → 맨 아래까지 넘겨 보기
   - 이미 로그인한 휴대폰에서는 버튼이 **"도란톡 열기"** 로 보여요. (정상)
2. **시크릿 창**에서 `dorantalk.com` 만 입력 → 소개 화면이 먼저 나오면 정상
3. 카카오톡 **나와의 채팅**에 `https://dorantalk.com/welcome` 을 보내 보기
   → 주황색 그림 + "도란톡 — 우리 가족만의 소식방" 미리보기가 나오면 성공

### 미리보기가 안 나오거나 예전 모습일 때
카카오톡 · 페이스북은 미리보기를 한동안 **저장해 두고 다시 써요.** 새로 읽게 하려면:
- **카카오톡**: https://developers.kakao.com/tool/debugger/sharing → 카카오 로그인 → 주소 입력 → **디버그** → **캐시 초기화**
- **페이스북 · 인스타**: https://developers.facebook.com/tools/debug → 주소 입력 → **디버그** → **다시 스크랩**

## D. 가입 경로 확인하기

홍보할 때는 [문구 모음](../marketing/promo-texts.md)의 **채널별 주소**를 쓰세요. (예: 인스타는 `…/welcome?from=insta`)
1~2주 뒤에 아래처럼 보면, **어디 홍보가 효과 있었는지** 알 수 있어요.

1. Supabase → **SQL Editor** → **+ New query** → 아래를 붙여넣기 → **Run**
```sql
-- 가입 경로별 가입자 수 (숫자만 봐요. 글 · 사진 · 채팅 내용은 보지 않아요)
select coalesce(raw_user_meta_data->>'signup_from', '(직접 · 기타)') as 가입경로,
       count(*) as 전체,
       count(*) filter (where created_at > now() - interval '7 days') as 최근7일
from auth.users
group by 1
order by 2 desc;
```
- `insta` 인스타 · `insta_ad` 인스타 광고 · `youtube` 유튜브 · `google_ad` 구글/유튜브 광고
- `blog` 블로그 · `naver_ad` 네이버 광고 · `cafe` 카페 · `daangn` 당근 · `family` 가족이 보낸 링크
- `(직접 · 기타)` 주소를 직접 입력했거나, 이번 업데이트 전에 가입한 사람

2. 전체 규모가 궁금할 때:
```sql
select (select count(*) from auth.users)            as 가입자,
       (select count(*) from public.family_groups)  as 가족그룹,
       (select count(*) from public.posts)          as 소식,
       (select count(*) from public.messages)       as 채팅;
```

## E. (선택) 구글 · 네이버 검색에 등록

검색으로 "도란톡"을 찾을 수 있게 해요. 안 해도 시간이 지나면 저절로 잡히지만, 등록하면 더 빨라요.

### E-1. 구글 (Search Console)
1. **https://search.google.com/search-console** → 구글 로그인 → **속성 추가**
2. 왼쪽 **도메인** 칸에 `dorantalk.com` → **계속**
3. **TXT 레코드**(`google-site-verification=…`)가 나오면 **복사** (이 화면은 열어 두기)
4. **가비아 DNS 관리툴** → **설정** → **레코드 추가**
   - 타입 **TXT** · 호스트 `@` · 값: 복사한 내용 → **확인** → **저장**
   - ⚠️ **새 줄을 추가**하는 거예요. 기존 TXT(`v=spf1 …`) · MX 줄은 절대 고치거나 지우지 마세요. (메일용)
5. Search Console로 돌아와 **확인** (안 되면 30분 뒤 다시)
6. 왼쪽 **Sitemaps** → `sitemap.xml` 입력 → **제출**

### E-2. 네이버 (서치어드바이저)
1. **https://searchadvisor.naver.com** → 네이버 로그인 → **웹마스터 도구**
2. 사이트 등록에 `https://dorantalk.com` → 소유 확인 화면에서 **HTML 태그** 선택
3. 나온 한 줄(`<meta name="naver-site-verification" content="…">`)을 **저에게 보내 주세요.** 앱에 넣어 드릴게요.
   (공개돼도 괜찮은 확인용 표시예요. 비밀 키가 아니에요)
4. 제가 넣은 뒤 **소유확인** → **요청 → 사이트맵 제출** → `https://dorantalk.com/sitemap.xml`

## F. (선택) 광고 계정 만들기

> 💳 광고비 결제 · 계정은 **직접** 만드셔야 해요. 처음엔 **하루 5천~1만 원, 1~2주**로 작게 시작하세요.
> 문구 · 이미지 · 주소는 [문구 모음](../marketing/promo-texts.md) **7번**에 다 있어요.

### F-1. 인스타그램 (가장 쉬움: 게시물 홍보하기)
1. 인스타 앱 → 프로필 → **≡** → **계정 유형 및 도구** → **프로페셔널 계정으로 전환** → **비즈니스** (무료)
2. 프로필 편집 → **링크 추가** → `https://dorantalk.com/welcome?from=insta`
3. 홍보 이미지로 게시물 올리기 → 게시물 아래 **게시물 홍보하기**
4. 목표: **웹사이트 방문 늘리기** → 주소: `https://dorantalk.com/welcome?from=insta_ad` · 버튼: **가입하기**
5. 타겟: **직접 만들기** → 지역 대한민국 · 나이 30~60 · 관심사 "가족", "육아", "부모"
6. 예산 · 기간 → 결제 수단 추가 → **게시물 홍보하기** (검토 후 보통 하루 안에 시작)

### F-2. 네이버 검색 광고 (파워링크)
1. **https://searchad.naver.com** → **신규가입** → 개인 광고주로 가입
2. **광고시스템** → **+ 새 캠페인** → **파워링크 유형** → 하루 예산 정하기
3. 광고그룹: 웹사이트 `https://dorantalk.com`
4. 키워드: 문구 모음의 **키워드 예시** 넣기
5. 소재: 제목 · 설명 · 연결 주소(`…/welcome?from=naver_ad`) 넣기
6. **비즈머니 충전** → 검토(검수)가 끝나면 시작
   - 검수에서 거절되면 그 사유를 캡처해 보여 주세요. 사이트에 필요한 것을 넣어 드릴게요.

### F-3. 구글 · 유튜브 광고
1. **https://ads.google.com** → **지금 시작하기** → 구글 로그인
2. 처음 화면에서 **전문가 모드로 전환** (아래쪽 작은 글씨) → **캠페인 없이 계정 만들기** → 국가 · 시간대(서울) · 통화(KRW)
3. **+ 새 캠페인** → 목표 **웹사이트 트래픽** → 유형 **검색**(글자 광고) 또는 **동영상**(유튜브, 쇼츠 영상이 있을 때)
4. 최종 도착 주소 `…/welcome?from=google_ad` → 광고 제목 · 설명은 문구 모음에서 복사
5. 결제 정보 → **게시**

## G. 무료 한도와 사용량 보는 곳

가족이 늘어나도 한동안은 무료로 충분해요. 아래 숫자는 지금 기준이고, 회사 사정으로 바뀔 수 있어요.

| 서비스 | 무료로 쓸 수 있는 양 (한 달) | 먼저 닿을 것 같은 것 | 보는 곳 |
|---|---|---|---|
| **Supabase** | 사진 저장 1GB · 사진 보기(내려받기) 5GB · DB 500MB · 사용자 5만 명 · 실시간 연결 200개 · 알림 서버 50만 번 | **사진 저장 1GB** (사진 약 2,000~3,000장) | 프로젝트 → 왼쪽 아래 **Usage** (또는 Organization → Usage) |
| **Vercel** (Hobby) | 전송량 100GB | 거의 닿지 않아요 | 프로젝트 → **Usage** |
| **Resend** | 하루 100통 · 한 달 3,000통 | 가입이 많은 날 | resend.com → **Usage** |

- 한 달에 한 번쯤 Supabase **Usage** 를 봐 주세요. **80%** 를 넘으면 알려 주세요. 사진을 더 작게 저장하는 등 방법을 같이 찾아요.
  (계속 넘기면 Supabase Pro(월 $25)로 바꿔야 할 수 있어요)
- Vercel Hobby는 **돈을 벌지 않는 개인 서비스**용이에요. 지금처럼 광고 없는 무료 앱은 괜찮지만,
  나중에 **유료 기능 · 수익**이 생기면 Vercel Pro(월 $20)로 바꿔야 해요.

## 홍보할 때 꼭 지킬 것
- **직접 만든 서비스라고 밝히기.** 이용자인 척 쓴 후기 · 댓글은 "추천 · 보증 등에 관한 표시 · 광고 심사지침" 위반이 될 수 있어요.
- **카페 · 커뮤니티 규칙 확인.** 대부분 홍보는 **홍보 게시판**에만 허용돼요.
- **동의 없이 문자 · 메일 · 쪽지로 광고 보내지 않기.** (정보통신망법 — 받는 사람이 미리 동의해야 해요)
- **장담하는 말 쓰지 않기.** "100% 안전", "평생 무료" 대신 "초대받은 가족만 볼 수 있어요", "지금은 무료예요".
- **문의 메일 확인.** 새 가족들의 문의는 `admin@dorantalk.com` → 지금 쓰는 지메일로 와요. (8단계)
