# 18단계 안내서 — 사진 탭 · 가족 프리미엄 (베타, 쿠폰)

> 소요 시간: 약 5분 · 비용: 무료 (아직 결제는 받지 않아요)

## 바뀐 것
1. **사진 탭 (누구나 무료)**
   - 그룹 아래쪽 탭이 **소식 · 채팅 · 사진 · 멤버** 4개가 됐어요.
   - 소식과 채팅에 올린 사진이 **달마다** 모여요. 누르면 크게 보고 옆으로 넘겨요.
   - "사진이 단톡방에 묻혀요" 문제를 제일 직접 풀어 주는 화면이에요.
2. **가족 프리미엄 (베타)** — 그룹마다 켜요. 한 명이 켜면 **그 그룹 가족 모두** 써요.
   - **사진 원본 화질**: 보통은 사진을 긴 쪽 1600px 로 줄여서 올리는데, 프리미엄은 4096px 까지 선명하게 올려요.
   - **한 달 사진 한 번에 내려받기**: 사진 탭에서 그 달 사진을 압축 파일(zip) 하나로 받아요. (`dorantalk-2026-11.zip`)
   - 기본 기능(소식 · 채팅 · 알림 · 사진 탭)은 **언제나 무료**예요. 프리미엄은 "더 좋게"만 해요.
3. **쿠폰으로 켜기** (결제는 아직 없어요)
   - 운영자가 쿠폰(`DORAN-XXXX-XXXX`)을 만들어 가족에게 주면, 그룹 멤버가 **멤버 탭 → 가족 프리미엄 → 쿠폰 넣기**.
   - 쿠폰 하나에 1~24개월. 쿠폰을 더 넣으면 기간이 이어서 늘어나요. 같은 쿠폰은 한 번만 쓸 수 있어요.
   - 만 14세 미만 계정은 쿠폰을 넣을 수 없어요. (돈과 관련된 일은 어른이)
   - 기간이 끝나면 **저절로 기본으로** 돌아가요. 그동안 올린 원본 사진은 그대로 남아요.
4. **관심 신청** — 프리미엄이 꺼진 그룹에는 **"프리미엄이 나오면 쓰고 싶어요"** 버튼이 있어요.
   누른 사람 수는 운영자의 **광고 성과 → 가족 프리미엄** 에 숫자로만 보여요. (돈을 받기 전에 정말 원하는 사람이 있는지 확인하는 용도)
5. 이용약관(제6조)과 개인정보처리방침에 가족 프리미엄(베타) · 관심 신청 · 쿠폰 사용 기록을 적었어요.

## 할 일 1: 데이터베이스 업데이트 (버전 12 → 13)
1. GitHub → **supabase → updates → v12_to_v13.sql** → 📋 전체 복사
   (아직 안 한 앞 버전 파일이 있으면 그것부터 차례로. 운영자 **연결 점검**이 순서를 알려 줘요)
2. Supabase → **SQL Editor** → **+ New query** → 붙여넣기 → **Run**
3. **"업데이트 완료! 버전 13"** 이 보이면 성공 → 연결 점검 "최신 버전(13)"

> 업데이트 전에도 앱은 그대로 돼요. 사진 탭은 바로 쓸 수 있고, 가족 프리미엄 칸만 안 보여요.

## 할 일 2: 쿠폰 만들어 주기 (운영자)
1. 운영자 계정(admin@dorantalk.com) → **내 정보 → 광고 성과 (운영자)** → 맨 아래 **가족 프리미엄 (베타)**
2. **개수**(1 · 3 · 5 · 10개) · **기간**(1 · 3 · 6 · 12개월) · **메모**(예: `베타 선물`, `외가`) → **쿠폰 만들기**
3. 새 쿠폰 옆 **복사** → 카톡 · 문자로 가족에게 보내기
4. 받은 가족: 그룹 → **멤버** 탭 → **가족 프리미엄** → 쿠폰 번호 넣기 → **쿠폰 넣기**
   (소문자 · 띄어쓰기 · 대시 없이 넣어도 돼요)

> 운영자 화면에는 쿠폰이 **썼는지 안 썼는지만** 보여요. 어느 가족이 썼는지는 보여 주지 않아요.

## 알아 둘 것
- **저장 공간**: 원본 화질 사진은 1장에 보통 2~4MB 라서 저장 공간을 더 써요. Supabase 무료는 사진 저장 **1GB** 예요.
  처음엔 **몇 가족에게만** 쿠폰을 주고, 한 달에 한 번 Supabase **Usage** 를 봐 주세요. (10단계 G)
- **돈을 받는 건 나중에**: 쿠폰을 **판매**하려면 사업자 등록 · 통신판매업 신고 · 결제 회사 계약이 먼저예요. (엄마와 함께)
  결제를 붙이면 "결제가 끝나면 쿠폰을 자동으로 넣어 주는" 방식으로 지금 만든 것을 그대로 이어서 써요.
- 동영상 올리기는 저장 공간을 아주 많이 써서, 결제가 생긴 다음에 프리미엄에 넣는 게 좋아요.
