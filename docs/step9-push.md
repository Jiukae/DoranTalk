# 9단계 안내서 — 휴대폰 알림 (카카오톡처럼)

> 소요 시간: 약 20분 · 비용: 무료 (Supabase 무료 요금제의 Edge Function 한도 안: 한 달 50만 번)
>
> 화면 이름은 가끔 바뀌어요. 비슷한 메뉴를 찾거나, 막히면 화면을 캡처해 보여 주세요.

가족이 **채팅 · 새 소식 · 내 글에 댓글 · 초대**를 보내면, 앱을 닫아 두어도 휴대폰에 알림이 와요.
알림을 누르면 그 채팅방(또는 글)이 바로 열려요. 그 채팅방을 보고 있을 때는 알림이 울리지 않아요.

| 순서 | 할 일 | 걸리는 시간 |
|---|---|---|
| A | 데이터베이스 업데이트 (버전 5 → 6) | 3분 |
| B | 알림 서버 만들기 (Supabase Edge Function) | 7분 |
| C | 알림 열쇠 만들어 넣기 | 5분 |
| D | 내 휴대폰에서 알림 켜기 · 시험 | 3분 |
| E | 가족에게 알리기 | - |

> 화면(앱)은 이미 올라가 있어요. B · C를 마치기 전까지는 "알림 켜기" 버튼 대신
> "알림 서버가 아직 준비되지 않았어요"라고 나와요. 다른 기능은 그대로 잘 돼요.

### 이렇게 동작해요 (보안)
- 앱이 "가족에게 알려 줘"라고 알림 서버에 부탁하면, 알림 서버는 **보낸 사람의 로그인 정보 그대로** DB에 받을 사람을 물어봐요.
  - 그래서 관리용 비밀 키(service role)는 이번에도 **어디에도 넣지 않아요.**
  - 같은 그룹 가족에게만, 방금 보낸 것만, 한 번만 보낼 수 있어요.
- 알림 내용은 **받는 휴대폰만 열어 볼 수 있게 암호화**해서 보내요. 구글·애플 알림 서버도 내용을 볼 수 없어요.
- 새로 필요한 비밀 값은 **알림 열쇠(VAPID) 하나**뿐이고, Supabase의 **Secrets**에만 넣어요.

---

## A. 데이터베이스 업데이트 (버전 5 → 6)

1. GitHub에서 **supabase** → **updates** → **v5_to_v6.sql** 을 엽니다.
2. 오른쪽 위 **복사 버튼**(네모 두 개 📋)을 눌러 **전체** 복사
3. **Supabase** → 왼쪽 **SQL Editor** → **+ New query** → 붙여넣기 → **Run**
   - 일부가 파랗게 선택돼 있으면 빈 곳을 한 번 클릭해 선택을 풀고 Run
   - "destructive operation" 경고 창이 뜨면 **Run this query** (가족 데이터는 지우지 않아요)
4. 결과에 **"업데이트 완료! 버전 6"** 이 나오면 성공
5. **https://dorantalk.com/#/check** → "데이터베이스 최신 버전 — 최신 버전(6)" 초록색 확인
   (맨 아래 "휴대폰 알림 서버 (선택)"은 아직 **?** 표시여도 괜찮아요. B · C를 하면 초록색이 돼요)

---

## B. 알림 서버 만들기 (Supabase Edge Function)

### B-1. 코드 복사
1. GitHub에서 **supabase** → **functions** → **push** → **index.ts** 를 엽니다.
2. 오른쪽 위 **복사 버튼**(📋)으로 **전체** 복사

### B-2. 함수 만들기
1. **Supabase** → 왼쪽 메뉴 **Edge Functions** (번개 모양 ⚡)
2. **Deploy a new function** → **Via Editor** (편집기에서 만들기)
3. 편집기에 들어 있는 예시 코드를 **모두 지우고**(Ctrl+A → Delete) 복사한 코드를 **붙여넣기**
4. 아래쪽(또는 위쪽) **Function name** 칸에 정확히 **`push`** (소문자 네 글자)
5. **Deploy function** → 1분쯤 기다리면 완료 ("Successfully deployed")

### B-3. "Verify JWT" 끄기
1. Edge Functions 목록에서 **push** 를 누르기
2. **Details**(또는 Settings) 탭 → **Enforce JWT Verification** (또는 "Verify JWT") 를 **끄기(OFF)** → **Save**
   - 이 알림 서버는 로그인 확인을 DB에서 직접 해요. 이 설정이 켜져 있으면 새 방식 키(sb_publishable)와 맞지 않아 알림이 안 갈 수 있어요.

---

## C. 알림 열쇠 만들어 넣기

알림 서버가 "도란톡이 보낸 알림"임을 증명할 때 쓰는 **열쇠 한 쌍**이에요. 처음 한 번만 하면 돼요.
(복사 · 붙여넣기가 편한 **컴퓨터**에서 하는 걸 추천해요)

### C-1. 열쇠 만들기
1. **https://dorantalk.com/#/push-setup** 을 열어요.
2. **열쇠 만들기** → 세 줄이 나와요: `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`
   - 열쇠는 **그 컴퓨터 안에서만** 만들어지고 어디에도 저장 · 전송되지 않아요.
   - 이 화면은 C-2가 끝날 때까지 **닫지 마세요.** (닫으면 다시 만들면 돼요)

### C-2. Supabase Secrets 에 넣기
1. **Supabase** → **Edge Functions** → 왼쪽(또는 위쪽) **Secrets**
   (못 찾으면: ⚙️ Project Settings → Edge Functions → Secrets)
2. **Add new secret**(또는 아래 빈 칸)에 하나씩, **이름은 정확히 그대로**:

   | Name (이름) | Value (값) |
   |---|---|
   | `VAPID_PUBLIC_KEY` | C-1 화면의 첫 번째 값 (**복사** 버튼) |
   | `VAPID_PRIVATE_KEY` | C-1 화면의 두 번째 값 |
   | `VAPID_SUBJECT` | `mailto:admin@dorantalk.com` |

3. **Save** (또는 Bulk save)
   - ⚠️ `VAPID_PRIVATE_KEY` 는 **비밀번호와 같아요.** Secrets 말고 다른 곳(카톡 · 메모 · 메일 · GitHub)에는 붙여 넣지 마세요.

### C-3. 확인
1. C-1 화면 아래 **알림 서버 확인** → 초록색 **"알림 서버가 준비됐어요!"**
2. **https://dorantalk.com/#/check** → "휴대폰 알림 서버 (선택)"이 **✓ 초록색**

> 빨간 안내가 나오면 그대로 따라 해 보세요.
> - "찾지 못했어요" → B-2의 이름이 `push` 인지, Deploy 했는지
> - "Verify JWT" → B-3
> - "한 쌍이 아니에요" → 열쇠를 **다시 만들어** 두 개를 **같이** 다시 넣기

## D. 내 휴대폰에서 알림 켜기 · 시험

### 안드로이드 (갤럭시 등)
1. **도란톡 안드로이드 앱**(15단계)을 열어요. (크롬에서도 되지만, 앱이어야 알림이 위에 팝업으로 떠요)
2. 오른쪽 위 **내 정보** → **알림** → **알림 켜기** → 휴대폰이 물으면 **허용**
3. **시험 알림 보내기** → 몇 초 안에 알림이 오면 성공 🎉
4. 앱을 **완전히 닫고**(최근 앱에서 밀어서), 다른 가족에게 채팅을 보내 달라고 해 보세요.
5. 알림이 **위쪽 아이콘으로만** 오고 팝업(앱 이름 · 내용)이 안 뜨면 → 아래 **"알림이 팝업으로 안 뜰 때"**

### 아이폰
1. 먼저 **사파리 → 공유 ⬆️ → "홈 화면에 추가"** 로 도란톡 아이콘을 만들어요. (아이폰은 이렇게 연 앱에서만 알림이 와요, iOS 16.4 이상)
2. **홈 화면의 도란톡 아이콘**으로 열고 → **내 정보** → **알림** → **알림 켜기** → **허용**
3. **시험 알림 보내기**

> 홈 화면에 들어가면 위쪽에 **"새 채팅이 오면 알려 드릴까요?"** 안내도 한 번 나와요. 거기서 켜도 돼요.

---

## E. 가족에게 알리기

가족 단톡방에 이렇게 보내 주세요:

> 도란톡에 **알림**이 생겼어요! 🔔
> 앱을 열면 위에 "새 채팅이 오면 알려 드릴까요?"가 나와요 → **알림 켜기** → **허용**
> 아이폰은 사파리에서 **홈 화면에 추가**한 도란톡 아이콘으로 열어야 알림이 와요.

---

## 알림이 팝업으로 안 뜰 때 (안드로이드)
안드로이드는 홈 화면에 추가한 앱(웹 앱)의 알림을 처음에 **"보통" 중요도**로 등록해요. 그래서 상태 표시줄에 아이콘만 뜨고, 카카오톡처럼 위에 팝업으로는 안 떠요.
(카카오톡 같은 앱은 스스로 "긴급"으로 등록하지만, 웹 앱은 코드로 이 중요도를 바꿀 수 없어요.) **휴대폰마다 한 번만** 바꿔 주면 돼요.
- **갤럭시**: 앱 화면의 **"알림 팝업"에 체크해도 진동만 오면**, 알림 **종류(카테고리)**가 아직 "보통"이에요.
  1. 가장 쉬운 방법: 도란톡 알림이 왔을 때 알림창에서 그 알림을 **길게 누르기** → **⚙ 설정** → **팝업으로 표시**(또는 "소리 및 팝업") 켜기
  2. 안 되면: 설정 → **알림** → **고급 설정** → **알림 카테고리 관리** 켜기 → **앱 알림** → **도란톡** → 맨 아래 **알림 카테고리** → 항목(예: 일반) → **팝업으로 표시** 켜기
- **다른 안드로이드 (픽셀 등)**: 설정 → **앱** → **도란톡** → **알림** → **일반** → **화면에 팝업** 켜기 (중요도가 보이면 **높음/긴급**)
- 앱 목록에 도란톡이 없으면(크롬 안에서 쓰는 경우): 같은 방법으로 **Chrome** → 알림 → **사이트** → dorantalk.com
- 앱 안에서도 볼 수 있어요: **내 정보 → 알림 → "알림이 위에 팝업으로 안 뜨나요?"** · **도움말 → 알림 받기**

## 알림이 안 올 때

- **휴대폰 인터넷**이 켜져 있어야 와요. 꺼져 있던 동안의 알림은 다시 연결되면 와요 (하루 안).
- **방해 금지 · 집중 모드**가 켜져 있지 않은지 확인
- **삼성 갤럭시 배터리 절약**: 설정 → 배터리 → 백그라운드 사용 제한 → "절전 상태 앱"에 크롬 · 도란톡이 있으면 빼 주세요.
- **알림이 막혀 있다고 나오면**: 내 정보 → 알림 카드의 안내대로 휴대폰 설정에서 허용 → 앱 새로고침
- **아이폰**: 설정 → 알림 → 도란톡 → 알림 허용 / 사파리 탭이 아닌 **홈 화면 아이콘**으로 열었는지
- 그래도 안 되면 `#/check` 화면을 캡처해서 보여 주세요.

## 알아 두면 좋은 것

- 알림은 **기기마다** 켜요. 휴대폰과 컴퓨터 둘 다 받고 싶으면 둘 다 켜 주세요.
- **로그아웃하면** 그 기기로는 알림이 오지 않아요. 다시 로그인하면 (전에 켜 두었던 기기는) 자동으로 다시 와요.
- 알림 열쇠를 **바꾸면**(C를 다시 하면) 가족 모두 알림을 한 번씩 다시 켜야 해요. 특별한 일이 없으면 바꾸지 마세요.
- 개인정보처리방침에 "알림을 켠 경우 수집하는 정보(알림 받을 주소)"와 "알림 전달 업체(구글 · 애플 · 모질라)"를 추가했어요.
