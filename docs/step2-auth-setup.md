# 2단계 안내서 — 회원가입 · 로그인 설정과 확인

> 소요 시간: 약 10분 · 컴퓨터에서 Supabase 설정 → 휴대폰으로 확인

2단계에서 만든 것: **회원가입(닉네임 포함)**, **로그인**, **로그아웃**, **닉네임 바꾸기**, **비밀번호 찾기**

Supabase 화면은 가끔 바뀌어서 메뉴 이름이 조금 다를 수 있어요. 막히면 화면을 캡처해서 보여 주세요.

---

## A. 이메일 인증 끄기 (강력 추천)

기본 설정은 "가입하면 인증 메일을 보내고, 메일의 링크를 눌러야 가입 완료"예요.
부모님께는 이 과정이 어렵고, 무료 메일 발송은 **1시간에 몇 통으로 제한**돼서
가족 여럿이 한꺼번에 가입하면 메일이 안 갈 수도 있어요. 그래서 끄는 걸 추천해요.

1. Supabase 프로젝트 화면 왼쪽 메뉴에서 **Authentication** (사람 모양 아이콘)을 누릅니다.
2. Authentication 안의 메뉴에서 **Sign In / Providers** 를 누릅니다.
   (예전 화면에서는 **Providers** → **Email** 을 누르면 나와요)
3. **Confirm email** 스위치를 찾아서 **끕니다(회색)**.
4. 아래쪽 **Save changes** (또는 **Save**) 버튼을 누릅니다.

> 같은 화면에 있는 **Allow new users to sign up** 은 **켜 둔 채로** 두세요. 꺼지면 가족이 가입할 수 없어요.
>
> ❓ 모르는 사람이 가입하면요? 가입은 할 수 있어도, **가족이 닉네임으로 초대하고 그 사람이 수락하기 전까지는**
> 우리 가족의 글·사진·채팅을 전혀 볼 수 없어요. (1단계에서 만든 보안 규칙)

---

## B. 앱 주소 알려 주기 (비밀번호 찾기 메일용)

"비밀번호를 잊으셨나요?"를 누르면 메일이 가는데, 그 메일의 링크가 **우리 앱(Netlify 주소)** 으로
돌아오게 하려면 Supabase에 앱 주소를 알려 줘야 해요.

1. **Authentication** → **URL Configuration** 을 누릅니다.
2. **Site URL** 칸을 지우고 Netlify 주소를 넣습니다. 예) `https://kim-family-talkfeed.netlify.app`
   → **Save** 누르기
3. 같은 화면 아래 **Redirect URLs** 에서 **Add URL** 을 누르고 아래처럼 입력 후 저장합니다.
   ```
   https://kim-family-talkfeed.netlify.app/**
   ```
   (`kim-family-talkfeed` 부분은 실제 내 Netlify 주소로 바꿔 주세요. 끝의 `/**` 까지 꼭 넣어 주세요.)

---

## C. (선택) 비밀번호 찾기 메일을 한국어로 바꾸기

기본 메일은 영어라 부모님이 헷갈릴 수 있어요.

1. **Authentication** → **Emails** (또는 **Email Templates**) 를 누릅니다.
2. **Reset Password** (또는 **Reset password**) 를 고릅니다.
3. **Subject heading(제목)** 칸을 아래로 바꿉니다.
   ```
   [TalkFeed] 비밀번호를 새로 정해 주세요
   ```
4. **Message body(본문)** 칸의 내용을 모두 지우고 아래를 붙여넣습니다.
   ```html
   <h2>TalkFeed 비밀번호 재설정</h2>
   <p>아래 버튼을 누르면 새 비밀번호를 정할 수 있어요.</p>
   <p><a href="{{ .ConfirmationURL }}" style="display:inline-block;padding:14px 24px;background:#c9581f;color:#ffffff;border-radius:12px;text-decoration:none;font-weight:bold;font-size:18px">새 비밀번호 정하기</a></p>
   <p>직접 요청하지 않았다면 이 메일은 무시하셔도 괜찮아요.</p>
   ```
5. **Save changes** 를 누릅니다.

> A에서 이메일 인증을 **켜 둔 채로** 쓰실 거라면, 같은 방법으로 **Confirm signup** 메일도 한국어로 바꿀 수 있어요.

## D. 휴대폰으로 확인하기

Netlify 주소를 휴대폰으로 열고, 아래 순서대로 해 보세요. (제가 올린 내용은 1분 안에 자동 반영돼요)

| # | 해 볼 것 | 이렇게 되면 정상 |
|---|---|---|
| 1 | 첫 화면 | **로그인** 화면이 보여요 |
| 2 | **회원가입 하기** → 닉네임 칸에 `ㅎㅎ` 입력 | "완성된 글자로 입력해 주세요" 빨간 안내 |
| 3 | 원하는 닉네임 입력 (예: 본인 이름) | 잠시 뒤 "✓ 사용할 수 있는 닉네임이에요" 초록 안내 |
| 4 | 이메일, 비밀번호 두 번 입력 → **가입하기** | "○○님, 환영해요!" 후 **홈 화면** |
| 5 | 오른쪽 위 **내 정보** → 닉네임 바꿔서 **닉네임 저장** | "닉네임을 바꿨어요" 초록 안내 |
| 6 | 앱을 닫았다가 다시 열기 | 로그인 상태 그대로 홈 화면 |
| 7 | **내 정보** → **로그아웃** → 확인 | 로그인 화면으로 돌아가요 |
| 8 | 비밀번호를 일부러 틀리게 로그인 | "이메일 또는 비밀번호가 맞지 않아요" |
| 9 | 바른 비밀번호로 로그인 | 홈 화면 |
| 10 | (가능하면) 다른 기기에서 **같은 닉네임**으로 가입 시도 | "이미 다른 사람이 쓰고 있어요" |

**Supabase에서도 확인해 보기 (선택)**
- **Authentication** → **Users**: 가입한 이메일이 보여요.
- **Table Editor** → **profiles**: 내 닉네임이 한 줄 들어가 있어요.

문제가 있으면 **어느 번호에서 어떤 글자가 떴는지** 알려 주시거나 화면을 캡처해 주세요.

- [ ] D. 휴대폰으로 1~9번 확인
