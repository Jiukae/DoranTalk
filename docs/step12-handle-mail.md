# 12단계 안내서 — 아이디 · 초대 메일 · 자녀 그룹 승인

> 소요 시간: 약 15분 · 비용: 무료
>
> 화면 이름은 가끔 바뀌어요. 비슷한 메뉴를 찾거나, 막히면 화면을 캡처해 보여 주세요. (열쇠가 보이는 부분은 가리고!)

## 바뀐 것
1. **아이디**: 모든 회원이 하나뿐인 아이디를 가져요. (2~20자, **한글도 돼요**)
   - **지금 회원은 지금 닉네임이 그대로 첫 아이디**가 돼요. 아무것도 안 해도 돼요. (내 정보에서 바꿀 수 있어요)
   - 닉네임은 이제 **다른 사람과 겹쳐도 돼요.** 그룹에서 보이는 이름이에요.
2. **초대는 아이디로**: 그룹의 **멤버** 탭 → 아이디 입력 → 초대 보내기
   - 초대받은 사람에게 **이메일로도** 알려 줘요. (앱 홈 화면 "받은 초대"에서 수락하는 것도 그대로)
   - 초대한 사람에게 상대방의 이메일은 **절대 보이지 않아요.** 메일은 데이터베이스가 직접 보내요.
3. **만 14세 미만도 그룹 만들기**: 새 그룹 만들기 → **보호자에게 승인 요청**
   - 보호자에게 **이메일**이 가고, 보호자 홈 화면에 **"자녀의 그룹 만들기 요청"** 카드가 떠요.
   - 보호자가 **내 정보 → 자녀 계정**에서 승인하면 그룹이 생기고(자녀가 방장), **보호자도 그 그룹의 멤버**가 돼요.
   - 보호자가 있는 그룹이면 **누가 초대해도** 자녀가 바로 수락할 수 있어요.
4. **"가족 그룹" → "그룹"**, 그룹 안의 **"가족" 탭 → "멤버" 탭** (소개 화면 · 홍보 문구는 그대로)

## A. 데이터베이스 업데이트 (버전 8 → 9)
1. GitHub에서 **supabase** → **updates** → **v8_to_v9.sql** 을 엽니다.
2. 오른쪽 위 **복사 버튼**(📋)으로 **전체** 복사
3. **Supabase** → **SQL Editor** → **+ New query** → 붙여넣기 → **Run**
   - "destructive operation" 경고 창이 뜨면 **Run this query** (회원 데이터는 지우지 않아요)
4. 결과에 **"업데이트 완료! 버전 9"** 가 나오면 성공
5. **https://dorantalk.com/#/check** → "데이터베이스 최신 버전 — 최신 버전(9)" 초록색 확인
   (맨 아래 **"초대 · 승인 요청 메일 (선택)"** 은 B를 하기 전까지 **?** 여도 괜찮아요)

## B. 메일 보내기 켜기
B를 안 해도 아이디 · 초대 · 승인은 **앱 안에서 다 돼요.** 메일만 안 가요.

### B-1. pg_net 켜기 (데이터베이스가 인터넷으로 요청을 보내는 기능)
1. Supabase → 왼쪽 **Database** → **Extensions**
2. 검색 칸에 `pg_net` → 오른쪽 스위치 **켜기** → (스키마를 물으면 그대로) **Enable extension**

### B-2. Resend 열쇠 만들기 (데이터베이스 전용)
1. **resend.com** → **API Keys** → **Create API Key**
2. Name `doran-db` · Permission **Sending access** · Domain `dorantalk.com` → **Add**
3. 나온 키(`re_…`)를 **Copy** — 이 창은 열어 두세요. (다시 볼 수 없어요)
   - ⛔ 이 키는 대화창 · GitHub · 카톡에 붙여넣지 마세요. 아래 **Vault**에만 넣어요.

### B-3. Vault(비밀 금고)에 열쇠 넣기
1. Supabase → 왼쪽 아래 **Integrations** → **Vault** (또는 **Project Settings → Vault**)
   - 처음이면 **Enable Vault** 같은 버튼이 나올 수 있어요 → 누르기
2. **Add new secret**
   - **Name**: `resend_api_key` ← **정확히 이 글자** (밑줄 2개, 모두 소문자)
   - **Secret**: B-2에서 복사한 `re_…` 키
   - **Save**
3. **https://dorantalk.com/#/check** → 새로고침 → **"초대 · 승인 요청 메일 (선택)"** 이 초록색 ✓ 이면 성공!

> 🔒 Vault에 넣은 열쇠는 **암호화**되어 저장되고, 데이터베이스 안의 메일 보내는 기능만 꺼내 쓸 수 있어요.
> 앱(휴대폰 화면)이나 다른 회원은 볼 수 없어요.

> 📨 메일 한도: Resend 무료는 **하루 100통**이고, 가입 인증 · 비밀번호 찾기 메일과 **합쳐서** 세요.
> 같은 사람에게 초대 메일은 **10분에 1통, 하루 5통까지**만 보내도록 막아 두었어요. (메일 폭탄 방지)

## C. 시험해 보기 · 알리기
1. 내 휴대폰 → **내 정보** → **아이디 · 닉네임** 에서 내 아이디 확인 (지금 닉네임과 같을 거예요)
2. 다른 계정(가족 또는 시험 계정)의 아이디로 아무 그룹 → **멤버** 탭 → **초대 보내기**
3. 그 계정의 **메일함**에 "[도란톡] ○○님이 "그룹이름" 그룹에 초대했어요" 가 오면 성공 (스팸함도 확인)
   - 안 오면: Supabase → **SQL Editor** 에서 아래를 실행해 결과를 캡처해 보여 주세요.
   ```sql
   select id, status_code, left(content::text, 200) as 내용, created
   from net._http_response order by created desc limit 5;
   ```
4. 회원들에게 알리기 (가족 단톡방에 그대로 보내도 돼요):
   > 📢 도란톡이 바뀌었어요! 이제 **아이디**로 초대해요. 내 아이디는 **내 정보**에서 볼 수 있어요. (처음엔 지금 닉네임과 같아요)
   > 초대받으면 **이메일**로도 알려 드려요. 그룹 안의 "가족" 탭 이름은 **"멤버"** 로 바뀌었어요.

## 알아 두기
- 자녀의 그룹 만들기 요청은 **휴대폰 알림**으로는 아직 안 가요 (메일 + 보호자 홈 화면 카드로 알려요).
  휴대폰 알림까지 원하면 알림 서버(9단계 Edge Function)를 한 번 다시 올려야 해요. 필요하면 말씀해 주세요.
- 개인정보처리방침에 **아이디 · 초대 알림 메일 · 자녀 그룹 승인**을 반영했어요. (내 정보 → 개인정보처리방침)
