# 11단계 안내서 — 만 14세 미만 자녀도 보호자 동의로 가입하기

> 소요 시간: 약 10분 · 비용: 무료
>
> 화면 이름은 가끔 바뀌어요. 비슷한 메뉴를 찾거나, 막히면 화면을 캡처해 보여 주세요.

## 어떻게 동작하나요?
1. **보호자가 먼저** 도란톡에 로그인 → **내 정보 → 자녀 계정 → 동의하고 가입 링크 만들기**
2. 동의 내용을 읽고 체크 → **내 비밀번호를 한 번 더 입력** (아이가 보호자 휴대폰으로 대신 동의하지 못하게)
3. **자녀 가입 링크**가 만들어져요 → 카카오톡 등으로 자녀에게 보내기 (7일 안에 **한 번만** 쓸 수 있어요)
4. 자녀가 링크를 열어 가입 → 아이가 이해하기 쉬운 말로 된 안내를 읽고 체크
5. 보호자가 가족 그룹의 **가족** 탭에서 자녀 닉네임으로 초대 → 자녀가 수락

**이미 가입한 자녀라면?** 새로 만들 필요 없어요. 자녀의 휴대폰(자녀 계정으로 로그인된 상태)에서 링크를 열면
**"이 계정에 보호자 동의 연결하기"** 버튼이 나와요. 누르면 지금 계정 그대로 보호자 동의 계정이 돼요. (지금 있는 그룹 · 글은 그대로)

**보호자 동의를 먼저 받은 뒤에** 아이의 정보(이메일 · 닉네임)를 받는 순서예요.

### 자녀 계정을 지키는 규칙 (데이터베이스가 지켜요)
- 자녀 계정은 **보호자가 들어 있는 가족 그룹에만** 초대받을 수 있어요.
  모르는 사람이 아이 닉네임을 입력해도 "찾을 수 없어요"로만 나와서, 아이 계정인지도 알 수 없어요.
- 자녀는 가족 그룹을 **직접 만들 수 없어요.**
- 보호자는 언제든 **내 정보 → 자녀 계정 → 계정 삭제**로 동의를 철회할 수 있어요. 자녀의 글 · 사진 · 채팅이 모두 지워져요.
- 동의 기록(동의한 보호자 계정, 동의 시각, 약관 버전)은 자녀 계정이 있는 동안 보관돼요.

## A. 데이터베이스 업데이트 (버전 7 → 8)
1. GitHub에서 **supabase** → **updates** → **v7_to_v8.sql** 을 엽니다.
2. 오른쪽 위 **복사 버튼**(네모 두 개 📋)을 눌러 **전체** 복사
3. **Supabase** → 왼쪽 **SQL Editor** → **+ New query** → 붙여넣기 → **Run**
   - "destructive operation" 경고 창이 뜨면 **Run this query** (가족 데이터는 지우지 않아요)
4. 결과에 **"업데이트 완료! 버전 8"** 이 나오면 성공
5. **https://dorantalk.com/#/check** → "데이터베이스 최신 버전 — 최신 버전(8)" 초록색 확인

> 업데이트 전에는 "자녀 계정" 화면에서 "서버(데이터베이스)가 예전 버전" 안내가 나와요. 다른 기능은 그대로 잘 돼요.

## B. 시험해 보기
1. 내 휴대폰 도란톡 → **내 정보** → **자녀 계정 (만 14세 미만)** → **동의하고 가입 링크 만들기**
2. **모두 동의해요** 체크 → 내 비밀번호 입력 → **동의하고 가입 링크 만들기**
3. **링크 복사** → 컴퓨터 크롬 **시크릿 창**(Ctrl+Shift+N)에 붙여넣어 열기
   - "보호자 ○○님이 가입을 허락했어요" 화면이 나오면 성공
4. 시험용 닉네임 · **평소 안 쓰는 이메일**로 가입 → (가입 인증 메일을 켰다면 메일의 버튼 누르기)
5. 내 휴대폰에서 아무 가족 그룹 → **가족** 탭 → 시험 닉네임으로 초대 → 시크릿 창에서 **수락하기**
6. 정리: 내 휴대폰 **내 정보 → 자녀 계정** → 시험 계정 옆 **계정 삭제**

## C. 지금 쓰는 가족에게 약관 변경 알리기
이용약관 제3조에 "약관을 바꿀 때는 미리 알린다"고 적어 두었어요.
이번 변경은 **아이도 보호자 동의로 가입할 수 있게 된 것**뿐이라 지금 회원에게 불리한 내용은 없지만, 가족 단톡방에 한 줄 알려 주세요.

> 📢 도란톡 약관이 조금 바뀌었어요. 이제 만 14세 미만 아이도 보호자(부모님)가 동의하면 가입할 수 있어요.
> (내 정보 → 자녀 계정) 자세한 내용: 내 정보 → 이용약관 · 개인정보처리방침

## 법적으로 알아 둘 것 (솔직하게)
- 「개인정보 보호법」 제22조의2: 만 14세 미만 아동의 개인정보를 처리하려면 **법정대리인의 동의**를 받고, 동의했는지 **확인**해야 해요.
- 시행령에 적힌 확인 방법 예시: 휴대폰 문자 · 카드 정보 · 휴대폰 본인인증 · 서면 · 이메일 · 전화, 그리고 **"그에 준하는 방법"**.
- 도란톡은 **보호자 본인 계정 로그인 + 비밀번호 재확인 + 보호자가 동의 내용을 직접 체크**하고, 그 기록을 남기는 방식이에요.
  휴대폰 본인인증처럼 강한 방법은 아니라서 **"그에 준하는 방법"** 에 기대는 방식이에요.
- 저는 법률 전문가가 아니에요. 더 확실히 하려면
  1. **개인정보침해신고센터 ☎ 118** (무료 상담)에 "가족 앱에서 이런 방식으로 법정대리인 동의를 받는데 괜찮은지" 물어보세요.
  2. 나중에 사업자가 되면 **휴대폰 본인인증**(PASS 등, 유료)을 붙일 수 있어요. 필요하면 말씀해 주세요.
- 개인정보처리방침에 **8. 만 14세 미만 아동의 개인정보** 조항을 새로 넣었고, 이용약관 **제4조 · 제11조**를 바꿨어요.
  (함께 고친 것: 웹사이트 전송 업체를 Netlify → **Vercel** 로, 메일 발송 목적에 "가입 확인" 추가)
