# 4단계 안내서 — 소식(글 · 사진 · 댓글 · 하트)

> 소요 시간: 약 10분 · 준비물: 컴퓨터(SQL 실행), 휴대폰 + 두 번째 계정(3단계에서 만든 것)

4단계에서 만든 것 (그룹 화면 아래 **소식** 탭)

- **글쓰기**: 맨 위 "눌러서 소식 쓰기" → 글 + **사진 최대 10장** → **올리기**
  - 휴대폰 사진은 올리기 전에 자동으로 줄여서(보통 0.3~0.6MB) 데이터와 저장 공간을 아껴요
- **소식 목록**: 최신 글이 맨 위. 사진은 4장까지 보이고 나머지는 "+2" 처럼 표시
  - 15개씩 보이고, 맨 아래 **이전 소식 더 보기**
  - 다른 가족이 새 글을 올리면 위쪽에 **"새 소식이 있어요"** 버튼이 떠요
  - 지금 보고 있는 **소식** 탭을 다시 누르면 새로고침
- **하트**: 🤍 누르면 ❤️ (다시 누르면 취소). 글 화면에 "○○님이 좋아해요"
- **댓글**: **댓글 쓰기** → 글 화면 아래 입력칸 → **등록**
- **내 글/댓글만 수정·삭제**: 내 글 오른쪽 위 **⋯** → 글 수정 / 글 삭제, 내 댓글 아래 **수정 / 삭제**
  - 글을 지우면 그 글의 사진도 사진 창고에서 함께 지워져요
- **사진 크게 보기**: 사진을 누르면 화면 가득. 옆으로 밀거나 ‹ › 로 넘기고 **✕ 닫기**

## A. 데이터베이스 업데이트 (꼭 해 주세요!)

4단계에서 보안 규칙을 하나 더 넣었어요(사진은 반드시 자기 그룹 폴더에만 저장).
**버전 4** 로 다시 실행해 주세요. 가입한 계정과 그룹은 그대로 남아요.

1. GitHub에서 **supabase/schema.sql** 을 열고 **새로고침(F5)**
2. 맨 위에 **`★ 버전 4 (4단계: 소식·사진·댓글·하트) ★`** 가 보이는지 확인 → **복사 아이콘**
3. Supabase **SQL Editor** → 입력칸 클릭 → **Ctrl+A** 로 전부 지우기 → **Ctrl+V** → **Run**
   (경고 창이 뜨면 **Run this query**)
   > ⚠️ **Run 누르기 전에 입력칸을 한 번 클릭**해서, 파랗게 칠해진(선택된) 글자가 없게 해 주세요.
   > 일부만 칠해져 있으면 Supabase는 **그 부분만** 실행해서 `syntax error at end of input` 오류가 나요.
4. **Success** 확인
5. 휴대폰에서 **https://talkfeed.netlify.app/#/check** → 4개 모두 초록색 ✓ ("최신 버전(4)")

## B. 휴대폰으로 확인하기

**나** = 내 휴대폰, **상대** = 같은 그룹의 두 번째 계정

| # | 누가 | 해 볼 것 | 이렇게 되면 정상 |
|---|---|---|---|
| 1 | 나 | 그룹 → **소식** 탭 | "아직 소식이 없어요" + 맨 위 "눌러서 소식 쓰기" |
| 2 | 나 | "눌러서 소식 쓰기" → 글 입력 → **📷 사진 추가** → 앨범에서 사진 3장 → **올리기** | "소식을 올렸어요! 🎉" 후 목록 맨 위에 글과 사진 |
| 3 | 나 | 사진 5장 이상 넣은 글 올리기 | 목록에 4장 + "+N" 표시 |
| 4 | 상대 | **소식** 탭 (이미 열려 있었다면 "새 소식이 있어요" 버튼 또는 탭 다시 누르기) | 내 글이 보여요. 상대 화면에는 **⋯** 버튼이 없어요 |
| 5 | 상대 | 🤍 **하트** 누르기 | ❤️ 하트 1 |
| 6 | 상대 | **댓글 쓰기** → 댓글 입력 → **등록** | 댓글이 바로 보여요 |
| 7 | 나 | 그 글을 열기 | "❤️ ○○님이 좋아해요" + 상대 댓글. 상대 댓글에는 수정/삭제 버튼이 없어요 |
| 8 | 나 | 사진 누르기 → 옆으로 밀기 → **✕ 닫기** | 사진이 크게 보이고 넘어가요 |
| 9 | 나 | 내 글 **⋯** → **글 수정** → 사진 하나 ✕ 로 빼고, 글 고치고 → **수정 완료** | 바뀐 내용이 보여요 |
| 10 | 상대 | 내 댓글 **수정** → 고치고 **저장**, 그다음 **삭제** | 바뀌었다가 사라져요 |
| 11 | 나 | 내 글 **⋯** → **글 삭제** → 확인 | 목록에서 사라져요 |
| 12 | (선택) | 컴퓨터 브라우저로도 열어 보기 | 가운데 정렬로 똑같이 보여요 |

**Supabase에서도 확인해 보기 (선택)**
- **Storage** → **family-photos** → 그룹 ID 폴더 → **posts**: 올린 사진들 (글을 지우면 사진도 사라져요)
- **Table Editor** → **posts / comments / post_likes**

문제가 있으면 **몇 번에서 어떤 글자가 떴는지** 알려 주시거나 화면을 캡처해 주세요.
