- 대신 고쳐야 할 문제 **7가지**를 찾았고(중간 2 · 낮음 3 · 참고 2), 코드는 **모두 고쳤어요.**
- 고친 것이 운영 서버에 적용되려면 아래 **할 일 1 · 2** 가 필요해요. (할 일 3 · 4 는 권장)

## 할 일 1: 데이터베이스 업데이트 (버전 14 → 15)
1. GitHub → **supabase → updates → v14_to_v15.sql** → 📋 전체 복사
2. Supabase → **SQL Editor** → **+ New query** → 붙여넣기 → **Run**
3. **"업데이트 완료! 버전 15"** 가 보이면 성공 → 연결 점검(**#/check**) "최신 버전(15)"

> 앱 화면은 그대로예요. 하루에 올릴 수 있는 양 · 일정 개수에 한도가 생겨요. (아래 "바뀐 것")

## 할 일 2: 알림 서버(push) 다시 올리기 ⚠️ 꼭
운영 서버를 확인해 보니 **알림 서버가 아직 예전 코드**예요. (19단계 "할 일 2"가 아직 안 됐어요)
이걸 해야 **생신 알림**이 가고, 아래 할 일 3(전용 열쇠)도 쓸 수 있어요.

1. GitHub → **supabase → functions → push → index.ts** → 오른쪽 위 **복사 버튼**(📋)으로 **전체** 복사
2. **Supabase** → **Edge Functions** (번개 ⚡) → **push** 누르기
3. 위쪽 **Code** 탭 → 편집기 글을 **모두 지우고**(Ctrl+A → Delete) **붙여넣기**
4. 오른쪽 아래 **Deploy updates** (또는 **Deploy**) → "Successfully deployed"
5. **Details** 탭 → **Enforce JWT Verification**(Verify JWT) 가 **꺼짐(OFF)** 인지 확인

## 할 일 3 (권장): 알림 서버 전용 열쇠
가족 휴대폰의 **알림 주소 목록**을 알림 서버만 받을 수 있게 하는 열쇠예요. (보고서 F2)
**순서가 중요해요**: ① 열쇠 만들기 → ② 알림 서버 Secrets → ③ Vault → ④ 시험 알림

### 3-1. 열쇠 만들기
1. Supabase → **SQL Editor** → **+ New query** → 아래 한 줄 붙여넣기 → **Run**
   ```sql
   select replace(gen_random_uuid()::text || gen_random_uuid()::text, '-', '') as push_db_key;
   ```
2. 나온 **64글자**를 복사해요. (아무도 맞힐 수 없는 무작위 글자예요)
   - ⛔ 이 글자는 대화창 · GitHub · 카톡에 붙여넣지 마세요. 아래 두 곳에만 넣어요.

### 3-2. 알림 서버 Secrets 에 먼저 넣기
1. **Supabase** → **Edge Functions** → **Secrets** (못 찾으면 ⚙️ Project Settings → Edge Functions → Secrets)
   — 9단계에서 `VAPID_PRIVATE_KEY` 를 넣었던 곳이에요
2. **Add new secret** → **Name**: `PUSH_DB_KEY` (정확히 대문자) · **Value**: 3-1의 64글자 → **Save**

### 3-3. 그다음 Vault(비밀 금고)에 넣기
1. Supabase → 왼쪽 아래 **Integrations** → **Vault** (12단계에서 `resend_api_key` 를 넣었던 곳)
2. **Add new secret** → **Name**: `push_db_key` (정확히 소문자) · **Secret**: **같은** 64글자 → **Save**

### 3-4. 확인
1. 앱 → **내 정보** → **알림** → **시험 알림 보내기**
2. "시험 알림을 보냈어요" + 휴대폰에 알림이 오면 성공 🎉
   - **"보내지 못했어요"가 계속 나오면** 두 곳의 글자가 서로 다른 거예요.
     Vault 에서 `push_db_key` 를 **Delete** 하면 바로 예전처럼 알림이 가요. 그다음 3-1부터 다시 해 주세요.

> 왜 Secrets 를 먼저? Vault 에 먼저 넣으면, 알림 서버가 열쇠를 갖기 전 몇 분 동안 알림이 멈춰요.

## 할 일 4 (권장): 운영자 계정 비밀번호
- `admin@dorantalk.com` 의 비밀번호가 **12자 이상**이고 **다른 사이트에서 안 쓰는 것**인지 확인해 주세요.
  (가족은 6자로도 가입할 수 있게 그대로 두었어요. 운영자 계정은 운영자 화면 · 쿠폰을 다루니까 더 튼튼하게)
- 바꾸는 법: 로그인 화면 → **"비밀번호를 잊으셨나요?"** → 메일의 버튼 → 새 비밀번호

## 할 일 5 (권장): 로그인 주소 허용 목록 확인
밖에서는 볼 수 없는 설정이라 시험하지 못했어요. 한 번만 눈으로 확인해 주세요.
1. Supabase → **Authentication** → **URL Configuration**
2. **Site URL** 이 `https://www.dorantalk.com` (또는 `https://dorantalk.com`) 인지
3. **Redirect URLs** 에 우리 주소(`https://www.dorantalk.com/**` 같은 것)만 있는지 — `*` 하나만 있거나 모르는 주소가 있으면 지우기
   - 이 목록은 "비밀번호 찾기 · 가입 인증 메일의 버튼이 돌아올 수 있는 주소"예요. 모르는 주소가 있으면 로그인 정보가 그쪽으로 갈 수 있어요.

## 바뀐 것 (앱에서 느낄 수 있는 것)
- 한 사람이 하루에 올릴 수 있는 양: **사진 300장 · 동영상 10개 · 프로필 사진 20번 · 모두 합쳐 500MB**
  (넘으면 "오늘은 더 올릴 수 없어요 … 내일 다시" 안내. 보통 쓰는 정도는 그대로 돼요)
- 가족 달력: 한 사람이 하루 **30개**, 한 그룹에 **300개**까지 · 달력 알림은 그룹마다 하루 **20번**까지
- 초대 메일: 그룹 이름 속 `. : / @` 는 띄어쓰기로 보여요 (예: "김씨네 2025.1" → "김씨네 2025 1")
- 알림을 눌렀을 때 도란톡 안의 화면만 열려요
- 이용약관 제6조 · 도움말에 하루 한도를 적었어요
