# 14단계 안내서 — Play 스토어에 도란톡 앱 올리기

> 소요 시간: 등록 1~2시간 + **비공개 테스트 14일** + 심사 며칠 · 비용: **25달러 (한 번만)**

## 어떻게 만들었나요?
- 도란톡 Android 앱은 **dorantalk.com 을 주소창 없이 앱 화면으로 여는 앱**이에요. (TWA: Trusted Web Activity)
  - 웹사이트를 고치면 **앱도 바로 같이 바뀌어요.** 앱을 다시 올릴 필요가 없어요.
  - 휴대폰의 크롬으로 열려서 로그인 · 알림 · 사진 올리기가 웹과 똑같이 돼요.
- 앱 이름 **도란톡** · 패키지 이름 **`com.dorantalk.app`** (한 번 정하면 못 바꿔요) · 안드로이드 7.0 이상
- 앱 파일(AAB)은 GitHub Actions 가 자동으로 만들어요. (`android/` 폴더, `.github/workflows/android.yml`)

## 받은 파일 (잃어버리면 안 돼요!)
| 파일 | 뭐예요? | 어디에 두나요? |
|---|---|---|
| `dorantalk-1.0.0.aab` | Play 스토어에 올리는 앱 파일 (업로드 키로 서명됨) | Play Console 에 올리면 끝 |
| `dorantalk-upload-key.jks` | **업로드 키** (앱 주인 증명서) | 보호자 컴퓨터 + USB · 클라우드에 **2곳 이상** 보관 |
| `업로드키-정보.txt` | 키 비밀번호와 지문 | 비밀번호는 **보호자 비밀번호 관리 앱**에 옮기고 파일은 지우기 |

> ⚠️ 업로드 키와 비밀번호는 **GitHub · 카톡 · 메일에 올리지 마세요.** 다음 업데이트 때 꼭 필요해요.
> 잃어버려도 Play Console → 앱 무결성 → **업로드 키 재설정 요청**으로 되살릴 수 있지만 며칠 걸려요.

## 1. 개발자 계정 만들기 — ⚠️ 보호자가 해야 해요
Google Play 개발자 계정은 **만 18세 이상**만 만들 수 있어요. 엄마나 아빠의 Google 계정으로 만들어요.

1. 보호자 컴퓨터에서 **https://play.google.com/console** → 보호자 Google 계정으로 로그인
2. 계정 유형: **개인** 선택 (회사가 없으니까)
3. 개발자 이름: **도란톡** (스토어에 보이는 이름)
4. 연락처 이메일: `admin@dorantalk.com` · 전화번호 · 주소 입력
5. **25달러** 카드 결제 (한 번만 내요)
6. **신분증 확인** (보호자 신분증 사진) → 보통 1~3일
7. Play Console 모바일 앱으로 **안드로이드 휴대폰 인증**을 하라고 나오면 따라 해요

> 개인 계정이라도 결제(인앱 구매)를 하지 않으면 집 주소는 스토어에 공개되지 않아요. 화면 안내를 꼭 읽어 주세요.

## 2. 앱 만들기
1. Play Console → **앱 만들기**
2. 앱 이름: `도란톡 - 가족 소식방` · 기본 언어: **한국어** · **앱** · **무료**
3. 체크박스(개발자 정책 · 미국 수출법) 모두 체크 → **앱 만들기**

## 3. 앱 콘텐츠 (정책 질문들) — 왼쪽 메뉴 **정책 및 프로그램 → 앱 콘텐츠**
| 항목 | 답 |
|---|---|
| 개인정보처리방침 | `https://dorantalk.com/privacy` |
| 앱 액세스 권한 | **일부 기능이 제한됨** → 심사용 계정 적기 (아래 3-1) |
| 광고 | **아니요, 광고 없음** |
| 콘텐츠 등급 | 설문 작성 (아래 3-2) |
| 타겟층 | 아래 3-3 |
| 뉴스 앱 · 정부 앱 · 금융 · 건강 | 모두 **아니요** |
| 데이터 보안 | 아래 3-4 |

### 3-1. 심사용 계정
심사하는 사람이 로그인해서 앱을 볼 수 있게 계정을 하나 만들어 줘요.
1. dorantalk.com 에서 새로 가입: 이메일 예) `playreview@dorantalk.com` (받을 수 있는 메일) · 아이디 `플레이심사`
2. 그 계정으로 그룹을 하나 만들고 글 · 사진을 두세 개 올려 두기
3. Play Console 에 이메일 · 비밀번호 · 설명 적기: `로그인 후 "플레이심사 그룹"을 누르면 소식 · 채팅 · 멤버 탭을 볼 수 있어요.`

### 3-2. 콘텐츠 등급 설문
- 이메일: `admin@dorantalk.com` · 카테고리: **소셜 또는 커뮤니케이션**
- 사용자끼리 소통 · 사진 공유: **예** (초대받은 그룹 안에서만)
- 폭력 · 선정성 · 도박 · 위치 공유 · 디지털 상품 구매: **아니요**

### 3-3. 타겟층 (연령)
도란톡은 **보호자 동의를 받은 어린이도 쓰는 가족 앱**이니까 솔직하게 골라요.
- 연령: 아이가 실제로 쓰는 나이부터 어른까지 골라요. 예) **9~12세 · 13~15세 · 16~17세 · 18세 이상**
- 어린이가 포함되면 Google **가족 정책**을 지켜야 한다고 나와요. 도란톡은 이미 이렇게 돼 있어요:
  - 광고 없음 · 위치 정보 안 받음 · 개인정보처리방침에 어린이 항목(제8조) 있음
  - 만 14세 미만은 **보호자 동의 링크**로만 가입 · 보호자가 있는 그룹에만 들어감
- 질문이 헷갈리면 **화면을 캡처해서 보여 주세요.** 같이 골라요.

### 3-4. 데이터 보안
- 데이터를 수집하나요? **예** · 전송 중 암호화? **예** (https) · 사용자가 삭제 요청 가능? **예**
- 계정 삭제 URL: `https://dorantalk.com/delete-account`
- 수집하는 데이터 (모두 **공유 안 함** · 목적은 **앱 기능 · 계정 관리**):
  | 종류 | 항목 |
  |---|---|
  | 개인 정보 | **이메일 주소**, **이름**(닉네임), **사용자 ID**(아이디) |
  | 사진 및 동영상 | **사진** |
  | 메시지 | **기타 인앱 메시지** (글 · 댓글 · 채팅) |
  | 앱 활동 | **기타 작업** — 가입 경로(`?from=` 홍보 주소). 목적: **분석** |
- "공유"는 **아니요**: Supabase · Vercel · Resend 는 우리 대신 일하는 처리 업체라서 Google 기준으로 공유가 아니에요.

## 5. 비공개 테스트 (새 개인 계정은 꼭 해야 해요)
2023년 11월 이후 만든 개인 계정은 **테스터 12명 이상이 14일 동안 계속** 테스트해야 정식 출시를 신청할 수 있어요.
1. **테스트 및 출시 → 테스트 → 비공개 테스트** → **트랙 만들기** (이름: `가족 테스트`)
2. **테스터** 탭 → **이메일 목록 만들기** → 가족 · 친구 **12명 이상**의 Gmail 주소
3. **새 버전 만들기** → **Play 앱 서명** 안내가 나오면 **계속** (Google 이 앱 서명 키를 관리해요)
4. **App Bundle 업로드** → `dorantalk-1.0.0.aab`
5. 출시 이름: `1.0.0` · 출시 노트: `도란톡 첫 버전이에요.` → **다음** → **저장** → **검토 시작**
6. 승인되면 **테스터** 탭의 **웹에서 참여** 링크를 테스터들에게 보내요 → 각자 **테스터 되기** → Play 스토어에서 설치
7. **14일 동안** 테스터가 빠지지 않게 해 주세요. (앱을 가끔 열어 주면 좋아요)
8. 14일 뒤 **대시보드 → 프로덕션 액세스 신청** → 테스트 소감 질문에 답하기 → 승인되면 **프로덕션**에 같은 AAB 로 출시

## 6. ⭐ 주소창 없애기 — Play 앱 서명 지문 알려 주기
Play 스토어에서 받은 앱은 **Google 의 앱 서명 키**로 다시 서명돼요. 이 지문을 `dorantalk.com` 에 등록해야 **위쪽 주소창이 사라져요.**
(등록 전에는 앱 위쪽에 `dorantalk.com` 주소 줄이 보여요. 앱은 정상으로 돼요.)
1. Play Console → **테스트 및 출시 → 설정 → 앱 서명** (또는 **앱 무결성 → 앱 서명**)
2. **앱 서명 키 인증서** 의 **SHA-256 인증서 지문** 복사 (`AB:CD:12:...` 처럼 생긴 긴 글자)
3. 그 글자를 Claude 에게 보내 주세요 → `.well-known/assetlinks.json` 에 추가해 드려요
   - 직접 하려면: GitHub → `.well-known/assetlinks.json` → ✏️ → `sha256_cert_fingerprints` 안에 `,` 를 찍고 `"복사한 지문"` 한 줄 추가 → Commit
4. 확인: **https://dorantalk.com/.well-known/assetlinks.json** 에 지문 2개가 보이면 끝 → 앱을 지웠다가 다시 설치하면 주소창이 사라져요

## 7. 다음에 앱을 업데이트할 때
- 화면 · 기능 수정은 **웹만 고치면 앱에 바로 반영**돼요. 앱을 다시 올릴 일은 거의 없어요.
- 앱 아이콘 · 이름 · 안드로이드 설정을 바꿀 때만: `android/app/build.gradle` 의 **versionCode 를 1 올리고** 새 AAB 를 만들어 서명해요. Claude 에게 부탁하면 돼요. (그때 업로드 키 파일과 비밀번호가 필요해요)
- (선택) GitHub 이 서명까지 하게 하려면: 저장소 **Settings → Secrets and variables → Actions → New repository secret** 에
  - `ANDROID_UPLOAD_KEYSTORE_B64` = `dorantalk-upload-key.jks.base64.txt` 의 내용 전체
  - `ANDROID_UPLOAD_KEYSTORE_PASSWORD` = 키 비밀번호
  - 그러면 **Actions → Android 앱 (AAB) → Run workflow** 한 번으로 서명된 AAB 가 나와요 (실행 화면 아래 **Artifacts**)
