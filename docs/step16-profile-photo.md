# 16단계 안내서 — 프로필 사진 · 동그라미 색 · 나이 표시

> 소요 시간: 약 3분 · 비용: 무료

## 바뀐 것
1. **프로필 사진 (데이터베이스 버전 11)**
   - **내 정보 → 프로필 사진 → 사진 올리기** 로 사진을 고르면, 가운데를 정사각형으로 잘라 작게(256px) 줄여서 올려요.
   - 위쪽의 큰 동그라미(📷 표시)를 눌러도 프로필 사진 칸으로 가요.
   - **사진 바꾸기** 를 하면 예전 사진은 저장소에서 지워요. **사진 지우기** 를 하면 색 동그라미로 돌아가요.
   - 사진은 **소식 · 댓글 · 채팅 · 멤버 목록 · 홈의 "내 정보" 버튼** 에 보여요.
2. **동그라미 색 고르기**
   - 사진이 없을 때 보이는 동그라미(닉네임 첫 글자) 색을 8가지 중에서 고를 수 있어요.
   - **자동** 을 고르면 예전처럼 닉네임에 따라 색이 정해져요.
3. **나이 표시**
   - 내 정보의 "보호자 동의로 가입한 계정이에요 · 보호자: …" 문구를 없애고, **만 14세 이상 / 만 14세 미만** 만 보여요.
     (가입할 때 고른 대로예요. 만 14세 미만은 보호자 동의 링크로 가입한 계정이에요)

## 누가 볼 수 있나요? (보안 규칙)
- 프로필 사진 · 색은 **내 닉네임을 볼 수 있는 사람만** 볼 수 있어요. (같은 그룹 멤버, 나를 초대했거나 내가 초대한 사람)
  모르는 사람은 서버가 사진 주소를 만들어 주지 않아서 볼 수 없어요.
- 사진은 **내 폴더(`avatars/내 id/`)에만** 올릴 수 있고, 남의 사진을 바꾸거나 지울 수 없어요.
- 만 14세 미만은 보호자가 있는 그룹에만 초대받을 수 있어서, 자녀의 프로필 사진도 가족만 봐요.
- 회원 탈퇴 · 보호자의 자녀 계정 삭제 때 프로필 사진도 함께 지워져요.
